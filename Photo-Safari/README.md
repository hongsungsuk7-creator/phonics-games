# Photo Safari 프로토타입 (v0.1)

> 근거 문서: `TRD\TRD_07_Photo Safari.md`
> 목적: 게임 흐름·난이도·조작감을 아이 테스트 전에 확인하는 플레이 가능한 시안. 정식 개발 코드가 아니다.

## 실행
- **간단히:** `index.html`을 Chrome에서 연다. 말하기(마이크)는 파일로 열면 막힐 수 있다.
- **말하기까지 확인:** `start.bat` 실행 → http://127.0.0.1:5196/ (파이썬 필요, Chrome 권장).
- 태블릿·스마트폰: PC에서 `start.bat` 실행 후 같은 와이파이에서 PC 주소(예: http://192.168.x.x:5196/)로 접속(Windows 방화벽 허용 필요). 가로 화면, 세로로 들면 돌려 달라는 안내가 나온다.
  - **주의:** 브라우저는 https가 아닌 주소에서 마이크를 막는다. 태블릿·휴대폰에서는 말하기 없이(별 ③ 없이) 진행된다. GitHub Pages(https)에 올리면 기기에서도 말하기가 된다.
  - iPhone·iPad(Safari)는 브라우저 음성 인식 지원이 제한적이다. 정식 버전은 팀 공통 발음 판정(phonics-api·기기 안 whisper)을 쓰므로 이 제약이 없다.
- 공용 파일 `../_shared/kit.js`, `../_shared/kit.css`를 함께 쓴다(Copy Cat·Little Detective·Shop & Count·Maze Quest·Photo Safari 공통: 화면 맞춤, 음성, 말하기 판정, 레벨 규칙, 결과 화면, QA 패널). 폴더째 옮길 때 `_shared`도 함께 옮긴다.

## 해 보는 순서
1. 연령을 고르고 START. 처음 한 번은 시범(SKIP 가능).
2. 미션(오른쪽 카드, 🔊 다시 듣기)을 듣고 캠프 장면에서 대상을 찾는다.
   - **장면 둘러보기:** 뷰파인더 밖을 좌우로 밀기(화면보다 1.5배 넓음).
   - **뷰파인더:** 흰 네모를 끌어 숨은 곳에 대면 빨간 초점 상자가 생기고 대상이 고개를 내민다.
   - **📷 셔터:** 찰칵. 빈 곳을 찍으면 횟수에 안 들어간다.
3. 맞으면 말하기 → 다음. 장면 곳곳에 숨은 Sound Seed 친구를 찍으면 보너스 친구 사진.

## TRD 반영 범위
| TRD 항목 | 반영 내용 |
|---|---|
| 숨는 자리·판정(4-1) | 장면 자리 12곳(behind the tent / on the rock / under the leaf / in the box / in the tree …), 초점 허용 범위 안에서만 초점 상자, 빈 사진은 시도로 치지 않음 |
| 연령별(4-2) | 5세 흐린 사진 카드+색 조건 / 6세 음성만(L1~2 작은 그림)+개수(1~3 무리) / 7세 위치 문장(L4~ 카드에 문장 글자) |
| 오답(4-3) | 1번째 흑백 사진 + 차이 안내("That's the pink mushroom. Find the brown mushroom!"), 2번째 정답 쪽 가장자리 반짝·장면 이동·대상 반짝, 3번째 Nunu가 찍어 보여 줌 |
| 레벨(6-2) | 숨은 대상 4~12, 드러난 비율 50%~15%, 비슷한 대상 0~4, 잠깐 숨는 대상 L5~6, 초점 허용 1.6~1.1, 큰 렌즈 L1~3 |
| 조작(9) | 뷰파인더 끌기 vs 장면 밀기 구분, 가장자리 자동 스크롤, 키보드(방향키·Space·A/D) |
| 튜터(8) | Nunu(Classmate Friends) 표정 3종, 숨은 친구 Sound Seed Explorers 5명, 말하기 5세 "brown mushroom" / 6세 "two mugs"(mice는 숫자만) / 7세 "The mouse is under the leaf." |

공통: 레벨은 고르지 않음(판 평균 별 2.0 이상 +1, 1.5 미만 두 번 연속 −1, 연령별 저장), 별 3개 기준(맞힘 / 첫 시도·힌트 없이 / 말하기), 손을 놓으면 8초 뒤 안내·15초마다 반복, 말하기 2번 실패 Good try·침묵 2번이면 넘어감·JUMP, 마이크 없으면 별 ③ 없이 진행, 언어 토글(처음 한국어), 16:9 + 4:3 + 스마트폰 가로, 세로는 돌려 달라는 안내.

## 프로토타입 한계 (정식 개발에서 바꿀 것)
- **그림:** 레슨팩 대표 이미지 대신 임시 그림(이모지, 색 바꾸기용 도형).
- **음성:** 레슨팩 공식 녹음·공통 TTS 목소리 대신 브라우저 내장 음성(기기마다 목소리가 다름).
- **발음 판정:** phonics-api 대신 브라우저 음성 인식(Chrome). 정확도·판정 기준이 팀 표준과 다르다.
- 공통 기록(`phonics.progress`), 아이 프로필, 컬렉션 꾸미기 화면은 아직 없다(결과 화면에 모은 개수만 표시).

## QA 옵션
- 화면 아래 가운데 **QA** 버튼: 레벨 강제, 말하기 모드(실제 인식 / 항상 통과 / 항상 오답 / 마이크 없음), 첫 판 시범(방문당 1회 / 매번 / 끄기), 저장 초기화.
- 주소 옵션: `?age=5|6|7&level=1~6&speech=real|ok|wrong|off&demo=auto|always|never&autostart=1&mute=1``
- 자동 점검(2026-11-25, Playwright·Chrome): 5세 L3(다른 대상 찍기 2번 → 힌트 → 정답 → 한 판 완주 → 결과), 6세 L4 개수 미션, 7세 L6 위치 미션(스마트폰, 장면 밀기·뷰파인더 끌기), 첫 판 시범 — 콘솔 오류 0.
