# Little Detective 프로토타입 (v0.1)

> 근거 문서: `TRD\TRD_04_Little Detective.md`
> 목적: 게임 흐름·난이도·조작감을 아이 테스트 전에 확인하는 플레이 가능한 시안. 정식 개발 코드가 아니다.

## 실행
- **간단히:** `index.html`을 Chrome에서 연다. 말하기(마이크)는 파일로 열면 막힐 수 있다.
- **말하기까지 확인:** `start.bat` 실행 → http://127.0.0.1:5193/ (파이썬 필요, Chrome 권장).
- 태블릿·스마트폰: PC에서 `start.bat` 실행 후 같은 와이파이에서 PC 주소(예: http://192.168.x.x:5193/)로 접속(Windows 방화벽 허용 필요). 가로 화면, 세로로 들면 돌려 달라는 안내가 나온다.
  - **주의:** 브라우저는 https가 아닌 주소에서 마이크를 막는다. 태블릿·휴대폰에서는 말하기 없이(별 ③ 없이) 진행된다. GitHub Pages(https)에 올리면 기기에서도 말하기가 된다.
  - iPhone·iPad(Safari)는 브라우저 음성 인식 지원이 제한적이다. 정식 버전은 팀 공통 발음 판정(phonics-api·기기 안 whisper)을 쓰므로 이 제약이 없다.
- 공용 파일 `../_shared/kit.js`, `../_shared/kit.css`를 함께 쓴다(Copy Cat·Little Detective·Shop & Count·Maze Quest·Photo Safari 공통: 화면 맞춤, 음성, 말하기 판정, 레벨 규칙, 결과 화면, QA 패널). 폴더째 옮길 때 `_shared`도 함께 옮긴다.

## 해 보는 순서
1. 연령을 고르고 START. 처음 한 번은 시범(SKIP 가능).
2. 어두운 방에서 손가락(마우스)으로 **돋보기**를 움직인다. 돋보기 안은 2배 확대로 보인다.
3. 반짝이는 단서 자리에 **1초 머물면** 단서가 오른쪽 수첩에 붙는다(6·7세는 힌트 문장도 읽어 줌).
4. 단서를 하나 이상 찾으면 아래 보기 중 정답을 고른다 → 불이 켜지며 정답 공개 → 말하기 → 다음.

## TRD 반영 범위
| TRD 항목 | 반영 내용 |
|---|---|
| 단서 규칙(4-1) | 단서 자리 4곳(쉬운 순서), 1초 머물면 획득, 단서 1개로 맞히면 보너스 집계, 첫 단서 전에는 보기를 고를 수 없음("Find a clue first!") |
| 연령별(4-2) | 5세 그림 단서 / 6세 그림+힌트 문장 / 7세 L5~6 그림 없이 힌트 문장만(수첩에 문장) + 손전등 배터리(다 되면 남은 단서를 모두 보여 줌) |
| 오답(4-3) | 1번째 "Find more clues!", 2번째 안 찾은 단서 자리가 크게 반짝(다 찾았으면 오답 하나 흐리게), 3번째 정답 공개 |
| 레벨(6-2) | 단서 4~2, 돋보기 32~22u, 보기 3~6, 방해 보기(다른 범주→같은 범주→비슷한 생김새→+혼동쌍), 가짜 반짝임 0~2, 단서 표시(발자국→반짝임→희미→없음) |
| 데이터(5-2) | 힌트 문장 13단어×3개(정답과 같은 m 첫소리 단어를 힌트에 쓰지 않음). match·meat는 정답에서 제외 |
| 튜터(8) | Piko 표정 4종(curious·puzzled·delighted·observant), 의뢰인 Popo·Dudu, 말하기 5세 "moon" / 6세 "It's a moon." / 7세 "It is a moon." |

공통: 레벨은 고르지 않음(판 평균 별 2.0 이상 +1, 1.5 미만 두 번 연속 −1, 연령별 저장), 별 3개 기준(맞힘 / 첫 시도·힌트 없이 / 말하기), 손을 놓으면 8초 뒤 안내·15초마다 반복, 말하기 2번 실패 Good try·침묵 2번이면 넘어감·JUMP, 마이크 없으면 별 ③ 없이 진행, 언어 토글(처음 한국어), 16:9 + 4:3 + 스마트폰 가로, 세로는 돌려 달라는 안내.

## 프로토타입 한계 (정식 개발에서 바꿀 것)
- **그림:** 레슨팩 대표 이미지 대신 임시 그림(이모지, 색 바꾸기용 도형).
- **음성:** 레슨팩 공식 녹음·공통 TTS 목소리 대신 브라우저 내장 음성(기기마다 목소리가 다름).
- **발음 판정:** phonics-api 대신 브라우저 음성 인식(Chrome). 정확도·판정 기준이 팀 표준과 다르다.
- 공통 기록(`phonics.progress`), 아이 프로필, 컬렉션 꾸미기 화면은 아직 없다(결과 화면에 모은 개수만 표시).

## QA 옵션
- 화면 아래 가운데 **QA** 버튼: 레벨 강제, 말하기 모드(실제 인식 / 항상 통과 / 항상 오답 / 마이크 없음), 첫 판 시범(방문당 1회 / 매번 / 끄기), 저장 초기화.
- 주소 옵션: `?age=5|6|7&level=1~6&speech=real|ok|wrong|off&demo=auto|always|never&autostart=1&mute=1``
- 자동 점검(2026-11-25, Playwright·Chrome): 5세 L1(단서 없이 고르기 안내 → 단서 2개 → 오답 2번 → 힌트 → 정답 → 한 판 완주 → 결과), 6세 L4 힌트 문장, 7세 L5 문장 단서 모드(스마트폰), 첫 판 시범 — 콘솔 오류 0.
