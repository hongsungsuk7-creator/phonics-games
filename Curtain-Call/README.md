# Curtain Call 프로토타입 (v0.1)

> 근거 문서: `TRD\TRD_02_Curtain Call.md`
> 목적: 게임 흐름·난이도·조작감을 아이 테스트 전에 확인하는 플레이 가능한 시안. 정식 개발 코드가 아니다.

## 실행
- **간단히:** `index.html`을 Chrome에서 연다. 말하기(마이크)는 파일로 열면 막힐 수 있다.
- **말하기까지 확인:** `start.bat` 실행 → http://127.0.0.1:5191/ (파이썬 필요, Chrome 권장).
- 태블릿·스마트폰: PC에서 `start.bat` 실행 후, 같은 와이파이에서 PC 주소(예: http://192.168.x.x:5191/)로 접속(Windows 방화벽 허용 필요). 가로 화면, 세로로 들면 돌려 달라는 안내가 나온다.
  - **주의:** 브라우저는 https가 아닌 주소에서 마이크를 막는다. 태블릿·휴대폰에서는 말하기 없이(별 ③ 없이) 진행된다. 기기에서 말하기까지 확인하려면 팀 게임처럼 GitHub Pages(https)에 올려야 한다.
  - iPhone·iPad(Safari)는 브라우저 음성 인식 지원이 제한적이다. 정식 버전은 팀 공통 발음 판정(phonics-api·기기 안 whisper)을 쓰므로 이 제약이 없다.

## 해 보는 순서
1. 타이틀에서 연령(5·6·7세)을 고르고 START. 처음 한 번은 시범(장갑 손)이 나온다(SKIP 가능).
2. 커튼이 열리고 배우(물건)가 하나씩 무대에 올라 인사한다 → 모래시계가 줄어드는 동안 기억한다.
3. 커튼이 닫혔다 열리면 무대가 바뀌어 있다. Party One의 질문에 답한다.
   - 5세 **사라짐**: 아래 보기에서 사라진 것 고르기
   - 6세 **사라짐** 또는 **바뀜**: 무대에서 새로 온 배우를 누르고 → 원래 있던 배우를 보기에서 고르기
   - 7세 **사라짐 2명**(보기에서 둘 다) 또는 **자리 바꿈**(무대에서 자리를 바꾼 둘을 차례로 누르기)
4. 맞히면 무대가 원래대로 돌아오고 객석 가족이 박수 → 말하기 → 다음. 한 판이 끝나면 결과(Bravo!).

## 프로토타입 한계 (정식 개발에서 바꿀 것)
- **그림:** 레슨팩 대표 이미지 대신 임시 그림(이모지, 색 바꾸기용 도형 5종). "배우 버전"은 그림 아래 발만 붙였다.
- **음성:** 레슨팩 공식 녹음·공통 TTS 목소리 대신 브라우저 내장 음성.
- **발음 판정:** phonics-api 대신 브라우저 음성 인식(Chrome).
- **캐릭터:** Party One 털 없는 버전은 표정 시트가 없어 한 가지 표정에 몸짓 애니메이션(통통 튀기·움찔)으로 반응을 표현했다(TRD 14장 이슈와 같음).
- **커튼:** three.js 셰이더 천 대신 CSS 커튼.
- 공통 기록(`phonics.progress`), 아이 프로필, My Theater 꾸미기 화면, 가족 주제 팩은 아직 없다.
