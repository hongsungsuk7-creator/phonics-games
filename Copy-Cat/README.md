# Copy Cat 프로토타입 (v0.1)

> 근거 문서: `TRD\TRD_03_Copy Cat.md`
> 목적: 게임 흐름·난이도·조작감을 아이 테스트 전에 확인하는 플레이 가능한 시안. 정식 개발 코드가 아니다.

## 실행
- **간단히:** `index.html`을 Chrome에서 연다. 말하기(마이크)는 파일로 열면 막힐 수 있다.
- **말하기까지 확인:** `start.bat` 실행 → http://127.0.0.1:5192/ (파이썬 필요, Chrome 권장).
- 태블릿·스마트폰: PC에서 `start.bat` 실행 후 같은 와이파이에서 PC 주소(예: http://192.168.x.x:5192/)로 접속(Windows 방화벽 허용 필요). 가로 화면, 세로로 들면 돌려 달라는 안내가 나온다.
  - **주의:** 브라우저는 https가 아닌 주소에서 마이크를 막는다. 태블릿·휴대폰에서는 말하기 없이(별 ③ 없이) 진행된다. GitHub Pages(https)에 올리면 기기에서도 말하기가 된다.
  - iPhone·iPad(Safari)는 브라우저 음성 인식 지원이 제한적이다. 정식 버전은 팀 공통 발음 판정(phonics-api·기기 안 whisper)을 쓰므로 이 제약이 없다.
- 공용 파일 `../_shared/kit.js`, `../_shared/kit.css`를 함께 쓴다(Copy Cat·Little Detective·Shop & Count·Maze Quest·Photo Safari 공통: 화면 맞춤, 음성, 말하기 판정, 레벨 규칙, 결과 화면, QA 패널). 폴더째 옮길 때 `_shared`도 함께 옮긴다.

## 해 보는 순서
1. 타이틀에서 연령을 고르고 START. 처음 한 번은 시범(장갑 손)이 나온다(SKIP 가능).
2. 왼쪽은 Duri의 견본 그림, 오른쪽은 그림자가 몰래 바꿔 놓은 내 캔버스.
   - **탭:** 물건을 누를 때마다 색(또는 종류)이 바뀐다.
   - **6·7세 개수:** 아래 서랍의 물건을 캔버스 물건 위로 끌면 +1, 캔버스 물건을 서랍으로 끌면 −1.
   - **7세 위치:** 물건을 빈 자리(점선)로 끌어 옮긴다. L5~6은 견본 대신 음성 지시 문장만 나온다.
3. 다 고쳤으면 **Done!** → 맞으면 말하기 → 다음. 결과 화면에 갤러리.

## TRD 반영 범위
| TRD 항목 | 반영 내용 |
|---|---|
| 캔버스 규칙(4-1) | 방 장면 6자리(on the shelf / on the table / under the table / on the chair / in the box / on the rug). 탭=변형 목록 순환, 개수=서랍 끌어 넣기·빼기(숫자 표시 없음), 위치=끌어 옮기기 |
| 연령별(4-2·6-1) | 5세 색·종류 / 6세 +개수 / 7세 +위치, L5~6 음성 지시 모드(지시 문장 다시 듣기) |
| 오답(4-3) | 1번째 맞게 고친 곳만 초록 테 + "Almost!", 2번째 남은 곳 하나 반짝(견본·캔버스), 3번째 그림자가 고쳐 줌. Done 전에는 정답 여부를 알려 주지 않음 |
| 레벨(6-2) | 다른 곳 2~6, 사물 묶음 3~6, 비슷한 색(L3~), 견본 가림 12/9/6초 + 다시 보기 2/1/1회 |
| 보상(7) | 그림마다 별 3개(완성 / 첫 Done에 완성·다시 보기 안 씀 / 말하기), 물감 방울(별 1개=1방울), 결과 화면 갤러리 |
| 튜터(8) | Duri+그림자 표정 3종(시트 4_그림자.png), 대사 영·한, 말하기: 5세 "blue mug" / 6세 "three mugs" / 7세 "The mouse is under the table." |

공통: 레벨은 고르지 않음(판 평균 별 2.0 이상 +1, 1.5 미만 두 번 연속 −1, 연령별 저장), 별 3개 기준(맞힘 / 첫 시도·힌트 없이 / 말하기), 손을 놓으면 8초 뒤 안내·15초마다 반복, 말하기 2번 실패 Good try·침묵 2번이면 넘어감·JUMP, 마이크 없으면 별 ③ 없이 진행, 언어 토글(처음 한국어), 16:9 + 4:3 + 스마트폰 가로, 세로는 돌려 달라는 안내.

## 프로토타입 한계 (정식 개발에서 바꿀 것)
- **그림:** 레슨팩 대표 이미지 대신 임시 그림(이모지, 색 바꾸기용 도형).
- **음성:** 레슨팩 공식 녹음·공통 TTS 목소리 대신 브라우저 내장 음성(기기마다 목소리가 다름).
- **발음 판정:** phonics-api 대신 브라우저 음성 인식(Chrome). 정확도·판정 기준이 팀 표준과 다르다.
- 공통 기록(`phonics.progress`), 아이 프로필, 컬렉션 꾸미기 화면은 아직 없다(결과 화면에 모은 개수만 표시).

## QA 옵션
- 화면 아래 가운데 **QA** 버튼: 레벨 강제, 말하기 모드(실제 인식 / 항상 통과 / 항상 오답 / 마이크 없음), 첫 판 시범(방문당 1회 / 매번 / 끄기), 저장 초기화.
- 주소 옵션: `?age=5|6|7&level=1~6&speech=real|ok|wrong|off&demo=auto|always|never&autostart=1&mute=1`&voice=1`(7세 음성 지시 모드 강제)
- 자동 점검(2026-11-25, Playwright·Chrome): 5세 L3(오답 2번 → 힌트 반짝 → 완성 → 말하기 → 한 판 완주 → 결과), 6세 L4(서랍 끌어 개수), 7세 L3(끌어 옮기기), 7세 L6 음성 지시 모드(스마트폰 844×390), 6세 L6 견본 가림, 첫 판 시범 — 콘솔 오류 0.
