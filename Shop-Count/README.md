# Shop & Count 프로토타입 (v0.1)

> 근거 문서: `TRD\TRD_05_Shop & Count.md`
> 목적: 게임 흐름·난이도·조작감을 아이 테스트 전에 확인하는 플레이 가능한 시안. 정식 개발 코드가 아니다.

## 실행
- **간단히:** `index.html`을 Chrome에서 연다. 말하기(마이크)는 파일로 열면 막힐 수 있다.
- **말하기까지 확인:** `start.bat` 실행 → http://127.0.0.1:5194/ (파이썬 필요, Chrome 권장).
- 태블릿·스마트폰: PC에서 `start.bat` 실행 후 같은 와이파이에서 PC 주소(예: http://192.168.x.x:5194/)로 접속(Windows 방화벽 허용 필요). 가로 화면, 세로로 들면 돌려 달라는 안내가 나온다.
  - **주의:** 브라우저는 https가 아닌 주소에서 마이크를 막는다. 태블릿·휴대폰에서는 말하기 없이(별 ③ 없이) 진행된다. GitHub Pages(https)에 올리면 기기에서도 말하기가 된다.
  - iPhone·iPad(Safari)는 브라우저 음성 인식 지원이 제한적이다. 정식 버전은 팀 공통 발음 판정(phonics-api·기기 안 whisper)을 쓰므로 이 제약이 없다.
- 공용 파일 `../_shared/kit.js`, `../_shared/kit.css`를 함께 쓴다(Copy Cat·Little Detective·Shop & Count·Maze Quest·Photo Safari 공통: 화면 맞춤, 음성, 말하기 판정, 레벨 규칙, 결과 화면, QA 패널). 폴더째 옮길 때 `_shared`도 함께 옮긴다.

## 해 보는 순서
1. 연령을 고르고 START. 처음 한 번은 시범(SKIP 가능).
2. 손님(Popo·Dudu·Little Big House 가족)이 주문한다. 🔊 order로 다시 듣기.
   - **담기:** 선반 물건을 탭하면 Tobi의 마법 가방(아래 줄)에 들어간다. 줄의 물건을 탭하면 다시 선반으로. 다 담으면 🔔 Ring.
   - **세기:** "How many ___?" → 숫자 카드 고르기.
   - **계산(7세):** 이야기 문제를 듣고 숫자 키패드로 답하기.
3. 맞으면 말하기 → 다음. 결과 화면에 쿠폰.

## TRD 반영 범위
| TRD 항목 | 반영 내용 |
|---|---|
| 문제 형식(4-1) | 담기 / 두 종류 담기 / 세기 / 계산(더하기·빼기 이야기) |
| 세기 도움(4-2) | 5세 L1~3 담을 때 숫자 읽기, 5세 L4~6·6세 L1~2 딸깍 소리만, 그 위는 조용히. **가방·선반·보기에 정답 숫자 강조 없음** |
| 오답(4-3) | 1번째 "Let's count again!" + 담은 물건 정렬, 2번째 담기=맞는 물건 반짝 / 세기=물건을 차례로 짚기(숫자 읽지 않음) / 계산=점 묶음 그림, 3번째 Tobi가 같이 세며 정답 공개 |
| 연령·레벨(6) | 수 범위(5세 1~5/1~10, 6세 1~10/1~20, 7세 합·차 10/20 이내), 선반 6~20개, 종류 2~4, 조건(종류→색→두 종류), 배치(줄→섞임→흩어짐) |
| 주문 제시 | 5세 그림 주문서+음성, 6세 L1~2 그림+음성, 그 위 음성만(7세는 문장 글자 표시) |
| 튜터(8) | Tobi 표정(curious·proud·surprised), 말하기 5세 숫자 / 6세 "three mugs" / 7세 "There are seven mugs." (복수 -s는 판정하지 않음, mice는 숫자만) |

공통: 레벨은 고르지 않음(판 평균 별 2.0 이상 +1, 1.5 미만 두 번 연속 −1, 연령별 저장), 별 3개 기준(맞힘 / 첫 시도·힌트 없이 / 말하기), 손을 놓으면 8초 뒤 안내·15초마다 반복, 말하기 2번 실패 Good try·침묵 2번이면 넘어감·JUMP, 마이크 없으면 별 ③ 없이 진행, 언어 토글(처음 한국어), 16:9 + 4:3 + 스마트폰 가로, 세로는 돌려 달라는 안내.

## 프로토타입 한계 (정식 개발에서 바꿀 것)
- **그림:** 레슨팩 대표 이미지 대신 임시 그림(이모지, 색 바꾸기용 도형).
- **음성:** 레슨팩 공식 녹음·공통 TTS 목소리 대신 브라우저 내장 음성(기기마다 목소리가 다름).
- **발음 판정:** phonics-api 대신 브라우저 음성 인식(Chrome). 정확도·판정 기준이 팀 표준과 다르다.
- 공통 기록(`phonics.progress`), 아이 프로필, 컬렉션 꾸미기 화면은 아직 없다(결과 화면에 모은 개수만 표시).

## QA 옵션
- 화면 아래 가운데 **QA** 버튼: 레벨 강제, 말하기 모드(실제 인식 / 항상 통과 / 항상 오답 / 마이크 없음), 첫 판 시범(방문당 1회 / 매번 / 끄기), 저장 초기화.
- 주소 옵션: `?age=5|6|7&level=1~6&speech=real|ok|wrong|off&demo=auto|always|never&autostart=1&mute=1`&type=put|put2|count|story`(문제 형식 강제)
- 자동 점검(2026-11-25, Playwright·Chrome): 5세 L2 담기(모자라게 담기 → 정렬 → 힌트 반짝 → 정답 시연 → 한 판 완주 → 결과), 6세 L4 색 조건 세기(차례로 짚기 힌트), 6세 L6 두 종류 담기(20개 흩어짐), 7세 L4 계산 키패드(점 힌트, 스마트폰), 첫 판 시범 — 콘솔 오류 0.
