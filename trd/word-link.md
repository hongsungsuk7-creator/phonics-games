# Word Link TRD (워드 링크)

> 트랙: 보드게임 · 버전 0.1 (제작 착수용) · 작성 2026-11-28
> 한 줄 소개: Dudu가 말한 한 단어 힌트에 맞는 카드를 판에서 모두 찾아 단추 가방에 묶어 담아요.

---

## 1. 개요

| 항목 | 내용 |
|---|---|
| 목적 | 한 단어 힌트(범주·색·크기·장소·연상)로 여러 카드를 묶으며 분류와 상위어(animals, food, colors)를 익힌다 |
| 대상 | 5~7세 + 초등 1학년(5세 K / 6세 A / 7세 B / 초1 G1). PC·태블릿·스마트폰, 교실은 큰 화면 |
| 학습 목표 | ① 상위어·범주 단어(animals, food, toys, things you wear) ② 색·크기 조건 듣기(red things, big things) ③ 장소·연상 단어(at the zoo, beach → sand, sun, swim) ④ 카드 단어 말하기 ⑤ "A car is not an animal." 같은 분류 문장 듣기 |
| 플레이 형태 | **1인**(5세~초1, Dudu가 출제) / **교실**(5세~초1, 교사가 출제, 반을 2팀으로) / **2인 이상**(7세: 한 기기 2팀 번갈아, 초1: 온라인 2팀 각 2명 이상 또는 2~3명 협동) |
| 인원 | 1인 기본. 교실 반 전체. 온라인 초1 4~8명 |
| 한 판 시간 | 5세 힌트 4개 약 3~4분 / 6세 5개 약 4~5분 / 7세 6개 약 5~6분 / 초1 판 하나 약 6~8분(추정) |
| 세계관 | 크로스백을 멘 꼼꼼한 친구 **Dudu**(Phonics Land Pocket Friends)는 흩어진 단추를 색깔별로 정리하는 걸 좋아한다. 오늘은 단추 대신 **그림 카드**가 마당에 흩어졌다. Dudu가 "Animals, 2!" 하고 무리 이름을 말하면, 아이는 그 무리에 맞는 카드를 찾아 Dudu의 크로스백에 담는다. 모은 무리는 "Dudu의 단추 상자"에 차곡차곡 쌓인다 |

## 2. 게임 흐름

1. **타이틀:** 햇살 비치는 마당, 카드가 바람에 살랑, Dudu가 빨강·파랑·노랑 단추를 들고 손을 흔든다. START. 왼쪽 위 키·Button Box(컬렉션), 오른쪽 위 언어·소리·나가기. 첫 터치에 음악 + 인사.
2. **START:** 모드 선택(혼자 하기 / 교실). 교실은 교사 잠금(길게 누르기 3초) 뒤 진입. 마이크 권한(팀 표준).
3. **첫 판 시범(방문당 1회, SKIP):** Dudu "Animals, 2!" → 장갑 손이 고양이 카드 탭 → 확인 단계(단어 듣고 따라 말하기 / 그림 2개 중 고르기) → 카드가 Dudu의 단추 색으로 바뀌며 크로스백으로 쏙 → 두 번째 카드도 같은 방식 → "이제 혼자 해 봐!".
4. **플레이(힌트 하나):**
   1. Dudu가 힌트와 개수를 말한다. 화면 위 힌트 칸에 범주 아이콘 + 개수 점(●●)이 뜬다(5세는 아이콘만, 글자 없음).
   2. 아이가 카드를 탭한다. 카드는 바로 열리지 않고 **확인 단계**를 거친다(4-2).
   3. 확인을 통과하고 힌트에 맞는 카드면 팀 색 단추가 붙고 크로스백으로 들어간다. 맞지 않는 카드는 부드럽게 제자리로 돌아가고 Dudu가 이유를 말한다.
   4. 개수를 다 찾으면 다음 힌트. 우리 색 카드를 다 찾으면 판이 끝난다.
5. **말하기:** 무리를 다 모으면 Dudu "Say them!" → 모은 카드 중 1장을 말한다(연령별). 통과 시 별 ③. JUMP 버튼.
6. **결과:** Dudu가 크로스백을 열어 단추 상자에 무리별로 정리하는 장면. 별, 이번 판 무리와 단어(다시 듣기), LEVEL UP!, 받은 단추. 홈 · 다시 · 다음.

## 3. 주요 게임 요소

| 요소 | 내용 |
|---|---|
| 배경 | 마당·놀이방·공원·바닷가 4종. 가운데 카드 판(3×3~5×5) |
| 목표 | 힌트에 맞는 카드를 개수만큼 정확히 찾는다. 우리 색 카드를 모두 모은다 |
| 장애물(난이도 요소) | 판 크기, 한 힌트의 개수, 같은 판에서 여러 범주에 걸치는 카드(red apple = food이면서 red), 비슷한 범주 방해 카드(car vs bus 중 vehicles 아닌 것), "아니야" 카드(6세~) |
| 조작 | 탭(카드 고르기, 확인 단계 보기 고르기), 힌트 다시 듣기 버튼, 7세~ 힌트 카드 목록에서 고르기(역할 바꾸기) |

## 4. 게임방식

### 4-1. 판과 힌트 규칙
- 판은 레슨 단어 + 범주 태그로 만든다(`js/board.js`). 판의 카드 중 **우리 색** 카드(힌트로 찾을 카드), 상대 색 카드(2팀 모드), 관계없는 카드, "아니야" 카드를 레벨표 비율대로 정한다.
- 힌트는 태그에서 만든다: 범주(animals) · 색(red things) · 크기(big things) · 장소(at the zoo) · 연상(beach, 초1). **각 힌트에 맞는 카드가 판에서 정확히 그 개수인지** 만들 때 검사한다(맞는 카드가 더 있으면 다른 힌트로 바꿈).
- 힌트 목록을 만들 때 **판에 있는 단어와 같은 힌트는 뺀다**(예: 판에 "fruit" 카드가 있으면 힌트 "fruit" 금지).
- 출제자(7세 역할 바꾸기, 교실 교사, 초1 팀 출제자)는 힌트를 **자판으로 치지 않고 힌트 카드 목록에서 고른다**. 개수는 + / − 버튼.
- **"아니야" 카드(6세~):** 어떤 힌트와도 관계없는 카드 1장. 고르면 차례만 넘어가고 감점·패배는 없다. Dudu가 그 카드를 살짝 옆으로 치운다.
- 5세는 팀 색 구분 없이 "힌트에 맞는 것 찾기"만 한다. 팀 색(빨간 단추 / 파란 단추)은 6세부터.

### 4-2. 연령별 문제 형식

| 연령 | 판 | 힌트 | 카드 열기 전 확인 | 예시 |
|---|---|---|---|---|
| 5세 | 그림 3×3 | 범주 + 개수, 범주 아이콘과 함께 | 단어를 듣고 따라 말하기(JUMP 가능, 통과 여부와 관계없이 진행) | "Animals, 2!" |
| 6세 | 그림 3×3~4×4 | 범주 또는 색·크기 | 단어를 듣고 따라 말하기 | "Red things, 3!" |
| 7세 | 그림 + 단어 4×4 | 범주·색·장소. L4~ 역할 바꾸기: 아이가 힌트 카드를 고르면 Dudu가 찾음 | 단어를 듣고 맞는 그림 2개 중 고르기 | "At the zoo, 3!" |
| 초1 | 단어 4×4~5×5 | 연상 단어 | 단어 글자를 보고 맞는 그림 2개 중 고르기 | "Beach, 3!" → sand, sun, swim |

- 7세 역할 바꾸기: 아이가 고른 힌트에 맞는 카드를 Dudu가 하나씩 집는다. Dudu가 개수만큼 다 맞히면 아이 힌트 성공(별 ①②). 힌트에 맞는 카드가 판에 개수보다 많거나 적으면 Dudu가 "Hmm, I found 3, not 2!"라고 말하고 다시 고르게 한다.

### 4-3. 정답·오답 처리
- **확인 단계 오답:** 그림 2개 중 틀린 그림을 고르면 카드가 열리지 않고 단어를 한 번 더 들려준다. 두 번째도 틀리면 맞는 그림이 살짝 반짝이고, 고르면 카드가 열린다(그 카드 별 ② 없음).
- **힌트에 맞지 않는 카드:** 카드가 부드럽게 흔들리며 제자리. Dudu "A car is not an animal."(태그로 문장 생성). 이 카드는 이번 힌트 동안 흐려진다.
- 같은 힌트에서 2번 틀리면 힌트: 맞는 카드 하나가 단추 색으로 반짝.
- 3번 틀리면 남은 정답 카드를 보여 주고 다음 힌트(그 힌트 별 ①만).
- 손을 놓으면 8초 뒤 장갑 손이 맞는 카드 근처를 가리킴. 15초마다 반복.

### 4-4. 별 3개 기준 (힌트마다)
① 개수만큼 다 찾음 ② 틀린 카드 없이, 확인 단계 첫 시도에 통과 ③ 말하기 통과

## 5. 콘텐츠·데이터

### 5-1. 레슨팩
- 첫 콘텐츠: **FP.K.U1L1** m 단어 18개 + 다른 단어 9개(egg lid ten heart fox gift kite gate doll). 한 판에 범주가 3개 이상 필요하므로 모자라면 같은 단원 이전 레슨 단어를 복습으로 섞는다.
- 그림: 파닉스 공통 대표 이미지 / 단어 음성: 레슨팩 공식 녹음
- 읽기: phonics-kit `lessonpack.py` → `js/words.js`

### 5-2. 추가 데이터

| 데이터 | 내용 | 만드는 방법 |
|---|---|---|
| 카드 태그 | 단어마다 범주·색·크기·장소 태그(예: mouse — animals, small, gray, at home) | 사람이 작성 → `data/tags.json`(레슨팩에 넣어 다른 보드게임과 공유 권장) |
| 힌트 단어 목록 | 범주·색·크기·장소·연상 힌트와 그림 아이콘, 연령별 사용 범위 | `data/hints.json` |
| 연상 묶음(초1) | 연상 힌트별 단어(beach → sand, sun, swim, shell) | `data/associations.json` |
| 힌트·분류 문장 음성 | "Animals, 2!", "A car is not an animal." | TTS + 받아쓰기 확인 |
| 혼동쌍 | mouse–mouth, meat–mitt 등 | `data/confusables.json` |

**태그 작성 규칙:** 한 단어에 범주 태그는 1개만(애매하면 빼기), 색은 그림에서 바로 보이는 색만, 크기는 big / small 중 분명한 것만 단다.

## 6. 레벨·난이도

### 6-1. 연령별 내용

| 항목 | 5세 (K) | 6세 (A) | 7세 (B) | 초1 (G1) |
|---|---|---|---|---|
| 카드 | 그림 | 그림 | 그림 + 단어 | 단어(그림은 확인 단계에만) |
| 힌트 종류 | 범주 | 범주·색·크기 | 범주·색·장소 + 역할 바꾸기 | 연상 |
| 확인 단계 | 따라 말하기 | 따라 말하기 | 듣고 그림 2개 중 고르기 | 글자 보고 그림 2개 중 고르기 |
| 말하기 | 단어 "cat" | 단어 | "A cat is an animal." 중 명사 | "Sand is at the beach." 중 명사 |
| 한 판 힌트 수 | 4 | 5 | 6 | 판 끝까지(우리 색 모두) |

### 6-2. 레벨 1~6 변수표

| 변수 | L1 | L2 | L3 | L4 | L5 | L6 |
|---|---|---|---|---|---|---|
| 판 크기(5세 / 6세 / 7세 / 초1) | 3×3 / 3×3 / 4×4 / 4×4 | 3×3 / 3×3 / 4×4 / 4×4 | 3×3 / 4×4 / 4×4 / 4×4 | 3×3 / 4×4 / 4×4 / 5×5 | 3×3 / 4×4 / 4×4 / 5×5 | 3×3 / 4×4 / 4×4 / 5×5 |
| 힌트 개수 | 1~2 | 2 | 2 | 2~3 | 3 | 3~4 |
| 방해 카드 | 다른 범주 | 다른 범주 | 비슷한 범주 1 | 비슷한 범주 2 | 여러 범주에 걸친 카드 | 여러 범주 + 혼동쌍 |
| "아니야" 카드(6세~) | 0 | 0 | 1 | 1 | 1 | 1 |
| 힌트 아이콘 | 그림 + 점 | 그림 + 점 | 그림 + 점 | 점만 | 점만 | 없음(음성만) |
| 역할 바꾸기(7세) | 없음 | 없음 | 없음 | 1회 | 2회 | 2회 |

### 6-3. 오르내림 규칙 (팀 표준)
판 평균 별 2.0 이상 +1 / 1.5 미만 어려운 판, 두 번 연속 −1 / 그 밖 유지. 아이·연령별 저장. 교실·온라인 판은 레벨에 반영하지 않는다(교사가 레벨 지정). QA용 `?level=`, `?age=`.

## 7. 보상·피드백

| 보상 | 얻는 법 | 쓰는 곳 | 저장 |
|---|---|---|---|
| 별 | 힌트마다 최대 3개 | 판 결과·레벨 판정 | 판별 최고 |
| 무리 카드 | 다 찾은 무리(animals, red things …) | Dudu의 단추 상자(무리별 단어 다시 듣기, 몇 번 모았는지) | 저장 |
| 단추 | 별 누적, 무리 10종 모으기 등 | Dudu 크로스백 꾸미기(단추 장식·끈 색), 단추 상자 배경 | 저장 |

- 정답 연출: 카드에 단추가 "톡" 붙고 크로스백으로 쏙. 무리를 다 모으면 Dudu가 "기쁨" 표정으로 가방을 두드린다.
- 오답 연출: 카드가 살짝 흔들리고 제자리. Dudu는 "놀람" 또는 "슬픔" 표정. 화남 표정은 쓰지 않는다.
- 결과 화면: 별, 이번 판 무리와 단어(다시 듣기, 말한 단어 초록 테), 찾은 수/전체, LEVEL UP!, 받은 단추, 홈 · 다시 · 다음. 교실 모드는 팀별 모은 카드 수.

## 8. 튜터·음성·발음 판정

### 8-1. 튜터
- **Dudu 두두**(Phonics Land Pocket Friends): 청록 네모 몸, 크림색 배, 남색 끈 크로스백(크림색 가방, 파란 단추 잠금). 시트 장면에서 빨강·파랑·노랑 단추를 색깔별로 정리한다.
- 시트: `01_Phonics_Friends Guide_v1/05_Pocket_Friends/Dudu_Views.png`, `Dudu_Expressions.png`(표정 6종: 기본·기쁨·화남·슬픔·놀람·불안), 그룹 `00_pocket.png`.
- 게임 연출을 시트 동작에 맞춘다: 맞힌 카드는 **Dudu의 크로스백**으로, 팀 색은 **Dudu의 빨간·파란 단추**, 결과 화면은 **단추 상자 정리** 장면. 정답 "기쁨", 오답 "놀람", 힌트 기다릴 때 "기본". 화남 표정은 쓰지 않는다.

| reveal | 3번 틀림 | These are the animals! | 이게 동물들이야! (힌트에 맞춰 생성) |
| yourTurn | 7세 역할 바꾸기 | Your turn! Pick a word card for me. | 네 차례야! 나한테 힌트 카드를 골라 줘. |
| tooMany | 역할 바꾸기 개수 틀림 | Hmm, I found 3, not 2! | 음, 2개가 아니라 3개 찾았어! |
| ask | 말하기 | Say one of them! | 하나 말해 봐! |
| sayAgain | 재시도 | One more time! | 한 번 더! |
| goodTry | 2번 실패 | Good try! Let's go on. | 좋은 시도였어! 다음으로 가자. |
| jumpTip | 첫 조용한 차례 | Want to skip? Tap the jump button! | 넘어가고 싶으면 점프 버튼을 눌러! |
| idle | 손을 놓았을 때 | Which cards go together? | 어떤 카드가 같은 무리일까? |
| great1~4 | 정답 | Into my bag! / Great sorting! / You found them all! / Super! | 가방에 쏙! / 정리 최고! / 다 찾았어! / 멋져! |

| levelUp | 레벨 업 | Level up! More cards this time! | 레벨 업! 이번엔 카드가 더 많아! |
| teamRed / teamBlue | 교실·2팀 차례 | Red button team! / Blue button team! | 빨간 단추 팀! / 파란 단추 팀! |

- 힌트·단어 음성이 나오는 동안 Dudu는 다른 말을 하지 않는다.

### 8-3. 음성
튜터·힌트·분류 문장: phonics-api TTS 공통 목소리 + whisper 되읽기. 단어: 레슨팩 공식 녹음 우선.

### 8-4. 말하기 대상 단어와 제외 단어

| 구분 | 내용 |
|---|---|
| 말하기 대상 | 5~6세 확인 단계: 누른 카드 단어 / 무리 완성: 모은 카드 중 1장(아이가 고름) |
| 판정 방식 | 모든 연령 **명사**가 들리면 통과(7세·초1 문장 틀의 is·an·at은 판정하지 않음) |
| 제외 | my. 범주 태그가 애매한 단어는 판에 넣지 않는다 |
| 주의 | mouse–mouth 같은 혼동쌍은 같은 판에 함께 두지 않는다(L6 듣기 확인 단계 방해 보기로만) |

### 8-5. 발음 판정 (팀 표준)
서버 analyze → judge, 안 되면 기기 안 whisper, 판정 불가면 별 ③ 없이 진행. 대기 8초, 끝 무음 1.2초, 최대 5초. 2번 실패 Good try, 침묵 약 20초 뒤 진행. 5세 확인 단계 따라 말하기는 판정 결과와 관계없이 카드를 연다(별 ③에만 반영).

## 9. 화면·UI 요구사항

- **기준:** 16:9, u = min(1vh, 100vw/177.78). 4:3, 스마트폰 가로(844×390, 932×430) 확인. 세로는 돌려 달라는 안내. 교실 모드는 TV·전자칠판 16:9.
- **상단 바(7.6u / 3u):** 타이틀 — 키·Button Box / 언어·소리·나가기. 게임 — 별·진행 / LEVEL + 힌트 다시 듣기 / 소리·나가기.
- **배치:** 가운데 카드 판(최대 100u × 70u), 위 힌트 칸(범주 아이콘 + 개수 점), 오른쪽 Dudu와 크로스백, 2팀 모드는 아래에 팀 단추 점수 줄.
- **카드 크기:** 5×5에서도 카드 한 장 12u 이상. 스마트폰 가로에서 5×5가 12u 미만이면 4×4로 낮춘다.
- **확인 단계:** 카드 위에 그림 2개 팝업(각 18u 이상). 팝업 밖을 누르면 취소.
- **터치:** 누르는 요소 최소 12u. 확인 단계 중에는 다른 카드 잠금.
- **키보드:** 방향키로 카드 이동, Enter 고르기, 1·2 확인 보기, M 말하기, J 점프, H 힌트 다시 듣기.
- **교실 화면:** 교사 화면에만 카드 테두리 팀 색(정답 지도) 표시 토글. 교실 큰 화면에서는 정답 색이 보이지 않게, 교사 기기 또는 교사 전용 창에서만 켠다.
- **예외:** 마이크 거부·없음 → 말하기 없이(5~6세 확인 단계는 듣기만 하고 열기). 오프라인·키 없음 → whisper. 첫 터치 전 소리 잠김. `prefers-reduced-motion` → 단추 반짝임 대신 고정 테두리.

### 10-1. 기술 단계

| 단계 | 이 게임에서 되는 것 | 필요한 것 |
|---|---|---|
| A. 정적 웹 | 1인 모드(5세~초1), 큰 화면 하나로 하는 교실 2팀(교사 기기 = 큰 화면, 정답 지도는 교사만 켬), 7세 한 기기 2팀 번갈아 | 런처·공용 kit·레슨팩, 기기 안 기록 |
| B. 교실 연결 | 교사 출제(교사 기기에만 정답 색), 반 전체 태블릿 투표 → 가장 많이 고른 카드 열기 | 실시간 게임 서버, 방 코드·QR 입장, 교사 콘솔 |
| C. 온라인 | 초1 온라인 팀전(팀당 2명 이상, 팀마다 출제자 1명), 2~3명 협동(Dudu 출제), 학생별 기록 | 실시간 서버 + API 서버·DB, 로그인 |

### 10-2. 실시간 이벤트 (B·C)

| 이벤트 | 방향 | 내용 |
|---|---|---|
| `room.join` | 학생 → 서버 | 방 코드, 프로필 아이콘, 팀 |
| `board.state` | 서버 → 전체 | 카드 단어·그림, 열림 여부, 차례 팀. **팀 색은 넣지 않는다** |
| `board.key` | 서버 → 출제자만 | 카드별 팀 색(빨강·파랑·관계없음·"아니야") |
| `hint.give` | 출제자 → 서버 | 힌트 id(목록에서 고른 것), 개수 |
| `card.vote` | 학생 → 서버 | 카드 id(교실 투표) / `card.pick`(온라인 팀원 대표 선택) |
| `check.answer` | 학생 → 서버 | 확인 단계 답(그림 id) |
| `card.result` | 서버 → 전체 | 열린 카드, 팀 색 공개, 맞음 여부, 다음 차례 |
| `game.end` | 서버 → 전체 | 팀별 모은 카드 수, 이번 판 무리와 단어 |

- 정답·차례·타이머는 서버가 관리한다. 출제자가 아닌 화면에는 열리기 전 카드의 팀 색을 절대 보내지 않는다.
- 투표·선택 마감은 서버 시계 기준. 마감 때 표가 없으면 차례만 넘긴다.
- 재접속 시 `board.state`(출제자는 `board.key` 포함)를 다시 보내 현재 판을 복원한다.

## 14. 알려진 이슈·보완 필요

- **높음 — 가정용 발음 판정 접속:** 키 없이 쓰는 방식을 정해야 한다. 그전까지는 기기 안 whisper만으로 동작.
- **높음 — 카드 태그 작성:** 판 만들기는 태그 품질에 달려 있다. 레슨당 태그 작성·검수 약 1시간 예상. 레슨팩에 넣어 Story Cards·Word Spectrum과 같이 쓰는 것을 제안.
- **중간 — 레슨당 단어 수:** 범주 3개 이상이 필요하다. U1L1 외 레슨은 단어가 6~10개라 이전 레슨 복습 단어를 섞어야 한다.
- **중간 — 범주 다툼:** "tomato는 fruit인가?"처럼 애매한 단어는 판에서 뺀다. 아이 테스트로 애매한 태그를 찾는다.
- **중간 — 교실 정답 지도:** A 단계에서 교사 기기가 곧 큰 화면이면 정답 지도를 켤 수 없다. 교사가 판을 미리 보는 "출제 준비" 화면(아이들이 보기 전)을 둘지 정한다.
- **낮음 — 초1 연상 묶음:** 연상 단어는 정답이 하나가 아니다. 묶음 목록에 없는 단어는 정답으로 인정하지 않으므로, 연상 힌트는 묶음이 분명한 것만 쓴다.
- **낮음 — Dudu 소품:** 단추 정리 동작·가방 여는 동작은 시트에 한 장면뿐이다. 필요한 포즈는 캐릭터 담당에게 요청한다.
