# Letter Tiles TRD (알파벳 타일)

> 트랙: 보드게임 · 버전 0.1 (제작 착수용) · 작성 2026-11-28
> 한 줄 소개: 글자 타일을 한 칸씩 이어 붙여 단어를 만들면, Stretch가 그 단어 모양의 다리가 돼요.

---

## 1. 개요

| 항목 | 내용 |
|---|---|
| 목적 | 글자 타일을 놓아 단어를 만들며 알파벳 → 첫소리 → 단어 철자로 이어지는 글자 감각을 기른다 |
| 대상 | 5~7세 + 초등 1학년(5세 K / 6세 A / 7세 B / 초1 G1). PC·태블릿·스마트폰, 교실은 큰 화면 |
| 학습 목표 | ① 알파벳 이름과 대문자·소문자 짝(5세) ② 첫소리와 첫글자 연결(6세) ③ CVC 단어·사이트 워드 만들기(7세) ④ 레슨 단어 철자, 단어에 글자를 붙여 새 단어 만들기(cat → cats, hat)(초1) ⑤ 완성한 단어 말하기 |
| 플레이 형태 | **1인**(5세~초1, 스테이지 퍼즐) / **교실**(5세~초1, 큰 화면 그림에 아이들이 차례로 나와 타일 하나씩) / **2인 이상**(7세: 한 기기 2명 번갈아 / 초1: 온라인 2~4명 차례 대전) |
| 인원 | 1인 기본. 교실 반 전체. 온라인 초1 2~4명 |
| 한 판 시간 | 5세 문제 6개 약 3~4분 / 6세 8개 약 4~5분 / 7세 8개 약 5~6분 / 초1 대전 약 6~8분(추정) |
| 세계관 | 블록 친구 **Stretch**(Phonics Land Shape Builders)는 연결 고리로 블록을 쌓고, 옆으로 길게 이어 **다리**가 된다. Shape Builders 친구들이 사는 블록 마을에 강이 흘러 친구들이 건너가지 못한다. 아이가 글자 타일을 한 칸씩 이어 단어를 만들면, Stretch가 그 단어 모양의 다리가 되어 친구가 건너간다. 만든 단어 다리는 마을 지도에 하나씩 놓인다 |

## 2. 게임 흐름

1. **타이틀:** 블록 마을 강가, Stretch가 블록 쌓기 → 다리 모양으로 길게 늘어나며 인사. START. 왼쪽 위 키·Bridge Map(컬렉션), 오른쪽 위 언어·소리·나가기. 첫 터치에 음악 + 인사.
2. **START:** 모드 선택(혼자 하기 / 교실). 교실은 교사 잠금(길게 누르기 3초). 마이크 권한(팀 표준).
3. **첫 판 시범(방문당 1회, SKIP):** 강 건너편에 고양이 그림 → Roll이 타일을 굴려 오고 Fold 보관함에 c·a·t 타일 → 장갑 손이 c를 Flatten 매트 첫 칸에 끌어 놓음("/k/") → a, t → Stretch가 딸깍 연결해 다리가 되고 단어 "cat"을 읽음 → 친구가 건너감 → "이제 혼자 해 봐!".
4. **플레이(문제 하나):**
   1. 강 건너편에 목표 그림(또는 5세는 글자 하나)이 나오고 Stretch가 말한다("Let's make **cat**!" 7세 / "What does bear start with?" 6세).
   2. Fold 보관함에 타일이 놓인다(정답 타일 + 방해 타일, 레벨표).
   3. 아이가 타일을 끌어 Flatten 매트의 칸에 놓는다. 놓는 순간 글자 이름(5세)·글자 소리(6세~)가 난다. 칸 근처에 놓으면 자동으로 붙는다.
   4. 칸이 다 차면 Stretch가 확인한다. 맞으면 단어 다리 완성 → 단어 전체를 읽어 줌 → 말하기.
5. **말하기:** "Read it!" → 아이가 단어를 말한다(5세는 글자 이름) → 통과 시 별 ③. JUMP 버튼.
6. **결과:** 마을 지도에 오늘 만든 다리들이 놓이는 장면. 별, 이번 판 단어(다시 듣기), LEVEL UP!, 받은 블록. 홈 · 다시 · 다음.

## 3. 주요 게임 요소

| 요소 | 내용 |
|---|---|
| 배경 | 블록 마을 강가 4종(시냇물·연못·큰 강·바닷가 다리). 아래 Flatten 매트(칸), 옆 Fold 보관함(손패), 위 목표 그림 |

## 4. 게임방식

### 4-1. 타일과 칸 규칙
- 타일은 크고 두꺼운 블록(Stretch의 살구색 블록 모양, 보라색 연결 고리). 한 타일에 글자 하나. 5세는 대문자·소문자 두 종류, 6세부터 소문자.
- 칸은 Flatten 매트 위에 단어 글자 수만큼 놓인다. 타일을 칸 반경 안(칸 크기의 60%)에 놓으면 자동으로 붙는다. 손이 서툴러도 실패하지 않게 한다.
- 정답 판정은 칸이 다 찼을 때만 한다(한 글자씩 맞다·틀리다를 알려 주지 않음, 단 5·6세 한 칸 문제는 바로 판정).
- **보관함 타일은 그 판에서 만들 수 있는 정답 단어가 반드시 하나 이상 있도록** 뽑는다.
- **단어 검사:** 일반 영어 사전이 아니라 **레슨 단어 + 연령별 허용 단어 목록**에 있는 단어만 인정한다. 사전에 있어도 아이에게 맞지 않는 단어는 목록에 넣지 않는다.
- 초1 대전: 각자 손패 타일 7개. 차례마다 ① 손패로 새 단어 만들기 또는 ② 판 위 단어에 타일을 붙여 다른 단어 만들기(cat → cats, cat → hat은 c를 h로 바꾸지 않고 h 타일 한 장으로 새 줄에 hat). 낼 수 없으면 Roll이 타일 1장을 굴려 준다. 내 타일을 먼저 다 쓰면 이긴다.

### 4-2. 연령별 문제 형식

| 연령 | 형식 | 칸 | 예시 |
|---|---|---|---|
| 5세 | 대문자·소문자 짝 맞추기 / 알파벳 이름을 듣고 타일 고르기 | 1 | "A" 칸에 a 타일 / "Find **m**!" |
| 6세 | 그림을 보고 첫글자 타일 놓기 | 1(그림 단어의 첫 칸만, 나머지 글자는 흐린 회색으로 미리 놓임) | 곰 그림 → **b**ear |
| 7세 | 그림을 보고 CVC 단어 만들기, 사이트 워드 | 3(사이트 워드 2~4) | c-a-t / t-h-e |
| 초1 | 레슨 단어 만들기(1인) / 판 위 단어에 붙여 새 단어 만들기(대전) | 3~5 | cat → cats, hat |

### 4-3. 정답·오답 처리
- 1번째 오답: 칸의 타일이 살짝 흔들리고 틀린 타일만 보관함으로 돌아간다(맞은 타일은 그대로). Stretch "Almost! Listen again." + 단어를 천천히 다시 읽어 줌.
- 2번째 오답: 힌트 — 다음 빈 칸이 빛나고 그 칸 글자 소리를 들려준다. 맞는 타일이 살짝 반짝.
- 3번째 오답: Stretch가 맞는 타일을 끼워 다리를 완성해 보여 주고 다음 문제(그 문제 별 ①만).
- 손을 놓으면 8초 뒤 장갑 손이 맞는 타일을 첫 빈 칸 쪽으로 끄는 시늉. 15초마다 반복.
- 초1 대전에서는 틀린 단어를 내면 타일이 손패로 돌아오고 차례가 넘어간다(감점 없음).

### 4-4. 별 3개 기준 (문제마다)
① 완성 ② 틀린 타일 없이 첫 시도에 완성(힌트 없이) ③ 말하기 통과

## 5. 콘텐츠·데이터

### 5-1. 레슨팩
- 첫 콘텐츠: **FP.K.U1L1** m 단어 18개 + 다른 단어 9개(egg lid ten heart fox gift kite gate doll). 5세 알파벳 문제는 레슨 글자(m) + 이미 배운 글자, 6세 첫글자는 레슨 단어 그림.
- **7세 CVC 문제에는 레슨의 CVC 단어(예: map, mat, mop, mug, men, ten, lid, fox)가 필요하다.** 한 판 8개가 모자라면 같은 단원 이전 레슨 CVC 단어를 섞는다.
- **초1은 ECP 레슨팩 밖의 단어 목록이 필요하다**(초1 교재 단어 + 붙여 만들 수 있는 짝 단어). 목록이 정해지기 전까지 초1 대전은 FP.K 전체 CVC 단어로 테스트한다.
- 그림: 파닉스 공통 대표 이미지 / 단어·글자 음성: 레슨팩 공식 녹음 → FPR K 공식 녹음 → TTS
- 읽기: phonics-kit `lessonpack.py` → `js/words.js`

### 5-2. 추가 데이터

| 데이터 | 내용 | 만드는 방법 |
|---|---|---|
| 알파벳 음성 | 26자 이름(A /eɪ/)과 소리(/æ/) | FPR K 공식 녹음 우선 → `data/letters.json` |
| 연령별 허용 단어 목록 | 7세 CVC·사이트 워드, 초1 단어 목록 | 사람이 작성·검수 → `data/allowed_{age}.json` |
| 붙여 만들기 짝(초1) | cat → cats, hat / man → map 등 | 허용 목록에서 자동 추출 후 사람이 확인 → `data/links.json` |
| 모양 혼동 글자 | b–d, p–q, m–n, u–n | `data/look_alike.json` |
| 혼동쌍(소리) | cat–cap, mat–map 등 | `data/confusables.json` |
| 안내 문장 음성 | "Let's make cat!", "What does bear start with?" | TTS + 받아쓰기 확인 |

**허용 목록 규칙:** 아이에게 맞지 않는 뜻의 단어, 고유명사, 줄임말은 넣지 않는다. 목록은 교재 담당 검수를 받는다.

## 7. 보상·피드백

| 보상 | 얻는 법 | 쓰는 곳 | 저장 |
|---|---|---|---|
| 별 | 문제마다 최대 3개 | 판 결과·레벨 판정 | 판별 최고 |
| 단어 다리 | 완성한 단어 | Bridge Map(마을 지도에 다리 놓기, 다리를 누르면 단어 다시 듣기) | 저장 |
| 블록 | 별 누적, 새 단어 다리 10개 등 | 블록 마을 꾸미기(집·나무·깃발), Stretch 연결 고리 색 | 저장 |

- 정답 연출: 타일이 "딸깍딸깍" 연결되며 Stretch가 다리로 늘어남 → Roll이 데굴데굴 다리를 건너 Expand 아치 문을 지나감. Stretch "기쁨" 표정.
- 오답 연출: 틀린 타일만 살짝 튕겨 보관함으로. Stretch "놀람" 표정. 화남 표정은 쓰지 않는다. 다리가 무너지는 연출은 쓰지 않는다.
- 결과 화면: 별, 이번 판 단어(다시 듣기, 말한 단어 초록 테), 완성 수/전체, LEVEL UP!, 받은 블록, 홈 · 다시 · 다음. 초1 대전은 각자 만든 단어 목록.

## 8. 튜터·음성·발음 판정

### 8-1. 튜터
- **Stretch**(Phonics Land Shape Builders, Apricot Stack): 살구색 네모 블록 3개가 보라색 연결 고리로 이어진 몸, 블록 얼굴(눈·입). 시트 변신 "Stack → Bridge"(쌓인 블록이 옆으로 길게 이어져 다리가 됨).
- 시트: `01_Phonics_Friends Guide_v1/04_Shape_Builders/Stretch_Views.png`, `Stretch_Expressions.png`, 그룹 `00_shape_builders.png`.
- 게임 연출을 시트에 맞춘다: **타일 = Stretch의 블록**, 칸에 놓으면 **연결 고리로 딸깍**, 단어 완성 = **Stack → Bridge 변신**. 정답 "기쁨", 오답 "놀람", 기다릴 때 "기본". 화남 표정은 쓰지 않는다.
- **타일 도우미(Shape Builders 4명):** **Roll**(노란 공) = 새 타일을 굴려 가져옴, 다리를 건너는 친구 / **Fold**(보라 아코디언) = 손패 타일 보관함(접힌 블록 칸) / **Flatten**(코랄 육각판 → 매트) = 타일을 놓는 판 / **Expand**(청회색 아치) = 완성 단어가 지나가는 아치 문. 도우미는 말하지 않고 동작·효과음만.

| reveal | 3번째 오답 | Here it is: c-a-t, cat! | 여기 있어: c-a-t, cat! (정답에 맞춰 생성) |
| ask | 말하기 | Read it! | 읽어 봐! |
| sayAgain | 재시도 | One more time! | 한 번 더! |
| goodTry | 2번 실패 | Good try! Let's go on. | 좋은 시도였어! 다음으로 가자. |
| jumpTip | 첫 조용한 차례 | Want to skip? Tap the jump button! | 넘어가고 싶으면 점프 버튼을 눌러! |
| idle | 손을 놓았을 때 | Drag a letter to the box! | 글자를 칸으로 끌어 봐! |
| great1~4 | 정답 | Bridge built! / Click, click, perfect! / You made a word! / Great building! | 다리 완성! / 딸깍딸깍 완벽해! / 단어를 만들었어! / 최고의 건설가! |

- 글자·단어 음성이 나오는 동안 Stretch는 다른 말을 하지 않는다. 한국어 모드에서도 글자 이름·소리·단어는 영어로 읽는다.

### 8-3. 음성
튜터·안내 문장: phonics-api TTS 공통 목소리 + whisper 되읽기. 글자 이름·글자 소리·단어: 레슨팩 공식 녹음 → FPR K 공식 녹음 → TTS. 글자 소리(/k/ 등)는 TTS로 만들지 않는다(공식 녹음 필수).

### 8-4. 말하기 대상 단어와 제외 단어

| 구분 | 내용 |
|---|---|
| 말하기 대상 | 5세: 글자 이름(A~Z 중 그 문제 글자) / 6세~초1: 완성한 단어 |
| 판정 방식 | 5세 글자 이름은 이름 소리 일치 / 6세~초1 단어 일치 |
| 제외 | my. 글자 이름 중 판정이 불안정한 짝(B/D/E/P/T/V, M/N)은 5세 말하기 대상에서 빼고 듣기·고르기로만 |
| 주의 | cat–cap, mat–map 같은 혼동쌍은 말하기 판정 대상에서 빼고(별 ③ 없이 진행), 듣기 방해 타일로만 쓴다 |

### 8-5. 발음 판정 (팀 표준)
서버 analyze → judge, 안 되면 기기 안 whisper, 판정 불가면 별 ③ 없이 진행. 대기 8초, 끝 무음 1.2초, 최대 5초. 2번 실패 Good try, 침묵 약 20초 뒤 진행.

## 9. 화면·UI 요구사항

- **기준:** 16:9, u = min(1vh, 100vw/177.78). 4:3, 스마트폰 가로(844×390, 932×430) 확인. 세로는 돌려 달라는 안내. 교실 모드는 TV·전자칠판 16:9.
- **상단 바(7.6u / 3u):** 타이틀 — 키·Bridge Map / 언어·소리·나가기. 게임 — 별·진행 / LEVEL + 단어 다시 듣기 / 소리·나가기.
- **배치:** 위 목표 그림(강 건너편, 24u), 가운데 Flatten 매트 칸(칸 16u, 최대 5칸), 아래 Fold 보관함(타일 16u, 최대 7개), 왼쪽 Stretch.
- **타일:** 16u 이상, 글자 크기 10u, 손가락에 가리지 않게 끄는 동안 타일이 손가락 위 6u로 올라옴. 대소문자 구분이 쉬운 학습용 글꼴(a·g 단층형).
- **터치:** 누르는 요소 최소 12u. 놓는 자리 자동 붙음 반경 = 칸 크기 60%.
- **키보드:** 방향키로 보관함 타일 고르기, Enter 다음 빈 칸에 놓기, Backspace 마지막 타일 빼기, M 말하기, J 점프, R 다시 듣기. (키보드는 접근성용 선택 조작이며 글자 직접 입력은 없다)
- **교실 화면:** 큰 화면에 목표 그림·매트·보관함을 크게. 아이가 나와 큰 화면을 직접 끌거나, 교사가 아이 대신 놓는다.
- **예외:** 마이크 거부·없음 → 말하기 없이. 오프라인·키 없음 → whisper. 첫 터치 전 소리 잠김. `prefers-reduced-motion` → 다리 변신 애니메이션 대신 페이드.

## 14. 알려진 이슈·보완 필요

- **높음 — 트랙 소속:** 5~7세 단계(대소문자·첫글자·CVC)가 파닉스 트랙 게임(파닉스 매치·토이캐치)과 내용이 겹친다. **5~7세 단계를 파닉스 트랙으로 옮길지**, 보드게임 트랙에 두고 초1 대전과 이어 갈지 정해야 한다. 옮기면 튜터 배정도 파닉스 트랙 기준으로 다시 본다.
- **높음 — 가정용 발음 판정 접속:** 키 없이 쓰는 방식을 정해야 한다. 그전까지는 기기 안 whisper만으로 동작.
- **높음 — 초1 단어 목록:** ECP 레슨팩이 초1 단어까지 이어지는지 확인해야 한다. 허용 목록·붙여 만들기 짝은 교재 담당 검수가 필요하다.
- **중간 — 글자 소리 녹음:** 글자 소리(/æ/, /k/)는 TTS로 만들 수 없다. 26자 공식 녹음이 모두 있는지 확인한다.
- **중간 — CVC 단어 수:** U1L1 외 레슨은 CVC 단어가 적다. 7세 한 판 8문제를 채우려면 이전 레슨 단어를 섞는다.
- **중간 — Shape Builders 표정:** 시트는 블록 얼굴(눈·입) 위주라 팀 기준 표정 6종(기본·기쁨·화남·슬픔·놀람·불안)이 모두 없을 수 있다. 필요한 표정(기쁨·놀람·불안)은 캐릭터 담당에게 요청한다. 같은 그룹이 Maze Quest에서 미로 장치로 나오므로 모델을 같이 쓴다.
- **낮음 — 모양 혼동 글자:** b/d, p/q는 5~6세에게 어렵다. L5~6에서만 쓰고 아이 테스트로 정답률을 본다.
- **낮음 — 키보드 조작:** 글자 직접 입력이 되지 않도록 키보드는 타일 고르기·놓기만 허용한다.
