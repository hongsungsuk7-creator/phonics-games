# Story Cards TRD (스토리 카드)

> 트랙: 보드게임 · 버전 0.1 (제작 착수용) · 작성 2026-11-28
> 한 줄 소개: Popo가 주머니에서 꺼낸 그림 카드를 설명하면 알맞은 그림을 골라요. 이번엔 내가 설명하면 Popo가 맞혀요!

---

## 1. 개요

| 항목 | 내용 |
|---|---|
| 목적 | 그림을 설명하는 영어를 듣고 알맞은 그림을 고르고, 스스로 그림을 설명하며 색·크기·기분·동작 표현을 익힌다 |
| 대상 | 5~7세(5세 K / 6세 A / 7세 B) + 초등 1학년(초1 G1). PC·태블릿·스마트폰·교실 큰 화면 |
| 학습 목표 | ① 묘사 단어(색·크기·기분·동작: red, big, happy, run) ② 구 듣기(a sad cat) ③ 문장 듣기(It is happy. / I see a dog.) ④ 단어 카드로 힌트 만들기 ⑤ 묘사 말하기 |
| 인원 | 1인 기본. 교실 모드(반 전체), 2인 이상(초1 온라인 2~6명) |
| 플레이 형태 | **1인**(5세~초1. 5세는 듣고 고르기만, 6세부터 역할 바꾸기) / **교실**(5세~초1, 교사나 아이 한 명이 이야기꾼, 나머지는 태블릿 투표 또는 차례로 나와 탭) / **2인 이상**(초1 각자 기기 온라인 2~6명). 7세 한 기기 2인은 두지 않음(투표를 가릴 수 없어서) |
| 한 판 시간 | 5세 라운드 5개 약 3분 / 6세 6개 약 4~5분 / 7세 6개 약 5~6분 / 초1 1인 8개 약 6~8분, 온라인은 인원 × 1라운드 약 8분(추정) |
| 세계관 | 원복 주머니에 사는 작은 친구 **Popo**(Phonics Land Pocket Friends)의 주머니에는 그림 카드가 잔뜩 들어 있다. Popo가 카드 한 장을 몰래 꺼내 "이런 그림이야!" 하고 설명하면 아이는 펼쳐진 카드 중에서 그 카드를 찾는다. 익숙해지면 아이가 이야기꾼이 되어 카드를 설명하고, Popo가 귀를 쫑긋 세우고 맞힌다. 함께 나눈 설명은 Popo의 주머니 앨범에 모인다 |

## 2. 게임 흐름

1. **타이틀:** 큰 원복 주머니에서 Popo가 쏙 고개를 내밀고 카드 한 장을 흔든다. START. 왼쪽 위 키·Popo의 주머니 앨범, 오른쪽 위 언어·소리·나가기. 첫 터치에 음악 + 인사.
2. **모드 고르기:** 혼자 하기(기본) / 교실(교사용, 보호자 잠금 영역에서 켬). 초1 온라인은 방 코드 입장(기술 단계 C).
3. **START:** 마이크 권한(팀 표준).
4. **첫 판 시범(방문당 1회, SKIP):** 그림 카드 3장이 펼쳐짐 → Popo가 "A happy dog!" → 장갑 손이 웃는 개 카드를 탭 → 카드가 뒤집혀 Popo 주머니 무늬가 보이며 정답 → "이제 혼자 해 봐!". 6세 이상은 첫 역할 바꾸기 라운드에서 한 번 더 짧은 시범(단어 카드를 고르는 손).
5. **플레이 — 듣고 고르기 라운드:**
   1. 그림 카드가 연령·레벨별 장수만큼 펼쳐진다.
   2. Popo가 주머니에서 카드를 몰래 확인하고 힌트를 말한다(다시 듣기 버튼).
   3. 아이가 카드를 탭한다. 정답이면 카드가 Popo 주머니로 쏙 → 힌트 다시 읽기 → 말하기.
6. **플레이 — 역할 바꾸기 라운드(6세~, 판의 절반):**
   1. 아이 앞에 그림 카드가 펼쳐지고, 그중 한 장에 "네 카드" 표시가 뜬다(Popo는 보지 않음).
   2. 아이가 힌트를 만든다: 6세 단어 보기 3개 중 1개 / 7세 단어 카드 2장으로 구 / 초1 문장 틀을 단어 카드로 채우기. 7세·초1은 말하기로도 할 수 있다.
   3. Popo가 힌트를 듣고 카드를 짐작한다. 맞히면 둘 다 기뻐하고, 틀리면 Popo가 "Tell me more!" → 아이가 단어를 하나 더 고른다(최대 2번).
7. **말하기:** 듣고 고르기 정답 뒤 "Say it!" → 아이가 힌트를 따라 말함(5세 단어, 6세 구, 7세 구, 초1 문장) → 통과 시 별 ③. 역할 바꾸기 라운드는 아이가 만든 힌트를 소리 내어 읽으면 별 ③. JUMP 버튼.
8. **결과:** Popo가 주머니 앨범을 펼쳐 이번 판 카드와 힌트를 보여 줌. 별, 이번 판 표현(다시 듣기, 말한 표현 초록 테), 맞힌 수/전체, 레벨 변화. 홈 · 다시 · 다음.

## 3. 주요 게임 요소

| 요소 | 내용 |
|---|---|
| 배경 | 커다란 원복 주머니 모양 무대. 카드는 주머니 앞 탁자 위에 펼쳐짐 |
| 목표 | 듣고 고르기: Popo가 설명한 카드를 찾는다 / 역할 바꾸기: Popo가 내 카드를 맞히도록 잘 설명한다 |
| 장애물(난이도 요소) | 카드 장수 증가, 한 가지만 다른 카드(빨간 공·파란 공), 두 가지 조건이 필요한 힌트(big + red), 문장 힌트, 역할 바꾸기에서 비슷한 카드 섞기 |
| 조작 | 탭(카드 고르기, 단어 카드 고르기), 끌기(단어 카드를 문장 틀 빈칸에 놓기, 7세·초1), 말하기 |
| 부가 요소 | 힌트 다시 듣기, Popo의 주머니 앨범(카드 + 힌트 다시 듣기), 주머니 꾸미기(단추·바느질 무늬), 다시 해보기 카드 |

## 4. 게임방식

### 4-1. 카드·힌트 규칙
- 그림 카드마다 **태그**(색·크기·기분·동작·물건)가 있다. 힌트는 이 태그로 만든다. 실시간 생성형 AI는 쓰지 않는다.
- 튜터 힌트 만들기: 정답 카드의 태그 중 **다른 펼친 카드에는 없는 태그**를 골라 힌트로 만든다. 한 태그로 구별이 안 되면 두 태그를 쓴다(big red ball).
- 펼칠 카드 고르기: 정답 카드와 태그가 1개만 다른 카드를 레벨에 따라 섞는다(L1은 모두 다른 물건, L6은 한 가지만 다른 카드 여러 장).
- 역할 바꾸기의 단어 보기: 아이 카드의 태그에서 1~2개 + 다른 카드에만 있는 태그 1~2개를 섞어 보여 준다. 보기는 모두 태그에서 나오므로 따로 막을 단어가 없다.
- 튜터 추측: 아이가 고른 단어와 카드 태그가 **가장 많이 겹치는 카드**를 고른다. 동점이면 "Tell me more!"로 단어를 하나 더 받는다. 아이 힌트가 정답 카드를 가리키지 않으면(다른 카드와 더 겹침) Popo는 그 카드를 고르고 "Oh, this one is big too!"처럼 이유를 말해 준다.

### 4-2. 연령별 문제 형식

| 연령 | 듣고 고르기 | 역할 바꾸기(내가 힌트) | 예시 |
|---|---|---|---|
| 5세 | 그림 3장, 단어 1~2개 힌트 | 없음 | "happy dog" |
| 6세 | 그림 4장, 짧은 구 | 단어 보기 3개(그림+소리) 중 1개 고르기 | big / red / sad |
| 7세 | 그림 5장, 구 | 단어 카드 2장으로 구 만들기(형용사 + 명사) 또는 말하기 | a sad cat |
| 초1 | 그림 6장, 한 문장 | 문장 틀을 단어 카드로 채우기 또는 말하기 | It is \_\_\_. / I see a \_\_\_. |

- 7세·초1 말하기 힌트는 음성 인식 결과에서 단어 카드 목록에 있는 단어만 쓴다. 한국어·목록 밖 단어는 무시하고 "Use the word cards!"로 안내한다.

### 4-3. 정답·오답 처리
- **듣고 고르기**
  - 1번째 오답: 고른 카드가 살짝 흔들리고 Popo가 힌트를 다시 말함 "Listen again!"
  - 2번째 오답: 힌트 — 힌트와 맞지 않는 카드 하나가 흐려짐(남은 카드는 2장 이상 유지).
  - 3번째 오답: 정답 카드가 주머니로 들어가며 공개 → 별 ①만, 다음 라운드
- **역할 바꾸기**
  - Popo가 틀리면 아이 잘못이 아니다. "Tell me more!" → 단어 하나 더(최대 2번). 그래도 못 맞히면 Popo가 "Show me!" 하고 아이 카드를 함께 보며 어떤 단어가 더 좋았을지 보여 준다(별 ①만).
- 손을 놓으면 8초 뒤 장갑 손이 힌트 다시 듣기 버튼을 가리킴. 역할 바꾸기에서는 아이 카드에만 있는 태그 단어 보기를 가리킴. 15초마다 반복.

### 4-4. 별 3개 기준 (라운드마다)
① 맞힘(역할 바꾸기는 Popo가 맞힘) ② 첫 시도에 맞힘(힌트·추가 단어 없이) ③ 말하기 통과

### 4-5. 모드별 규칙
- **1인:** 위 4-2. 6세부터 판의 절반은 역할 바꾸기.
- **교실:** 교사(또는 교사가 고른 아이)가 이야기꾼. 큰 화면에 카드를 펼치고 교사 화면에만 정답 카드 표시. 아이들은 태블릿으로 투표(B 단계)하거나, 차례로 나와 탭(A 단계). 투표 결과를 막대로 보여 주고 정답 표현을 다 같이 말한다. 점수 없이 반 별만.
- **온라인(초1, 2~6명):**
  1. 교사나 아이가 방을 만들고 레슨·그림 세트를 고른다.
  2. 각자 그림 5장을 받는다.
  3. 이야기꾼이 자기 카드 1장 + 힌트를 낸다(단어 카드 문장 틀, 60초).
  4. 나머지가 힌트에 맞는 자기 카드를 낸다(30초).
  5. 섞인 카드에 투표한다(30초). 자기 카드에는 투표할 수 없다.
  6. 점수: 일부만 맞히면 이야기꾼과 맞힌 사람 +3, 모두 맞히거나 모두 틀리면 이야기꾼 0·나머지 +2, 내 카드가 받은 표마다 +1. 모두 한 번씩 이야기꾼을 하면 끝.
  7. 2명이면 서버가 힌트와 태그가 가장 덜 겹치는 더미 카드 2장을 섞는다.
  8. 마감까지 못 낸 사람은 손패에서 자동 제출(기록에 자동 제출 표시).

## 5. 콘텐츠·데이터

### 5-1. 레슨팩
- 첫 콘텐츠: **FP.K.U1L1** m 단어 18개 + 다른 단어 9개(egg lid ten heart fox gift kite gate doll)
- 그림: 파닉스 공통 대표 이미지 + **묘사용 변형 그림**(색·크기·기분·동작이 다른 버전) / 단어 음성: 레슨팩 공식 녹음
- 읽기: phonics-kit `lessonpack.py` → `js/words.js`

### 5-2. 추가 데이터

| 데이터 | 내용 | 만드는 방법 |
|---|---|---|
| 묘사 카드 | 단어마다 변형 그림 3~6장(예: monkey — happy·sad·big·small·running) | 공통 대표 이미지 기반 변형 그림 제작 → `data/cards.json` |
| 카드 태그 | 카드마다 색·크기·기분·동작·물건 태그 | 사람이 지정(레슨팩 공통 태그) → `data/cards.json` |
| 묘사 단어 목록 | 연령별 쓸 수 있는 형용사·동작 단어(5세: happy sad big small + 색 / 6세 + hot cold long short / 7세·초1 + run jump sleep 등) | `data/describe_words.json` |
| 힌트·문장 틀 | "a ___ ___", "It is ___.", "I see a ___." | `data/frames.json` |
| 구·문장 음성 | 튜터 힌트(a happy dog, It is red.) | TTS + 받아쓰기 확인(단어는 공식 녹음 이어 붙이지 않고 문장 단위로 생성) |
| 혼동쌍 | mouse–mouth, meat–mitt 등 | `data/confusables.json` |

**카드 작성 규칙:** 한 카드는 한 물건(동물) + 눈에 띄는 특징 1~2개. 배경은 단순하게. 두 카드가 같은 태그 조합을 갖지 않게 한다.

## 6. 레벨·난이도

### 6-1. 연령별 내용

| 항목 | 5세 (K) | 6세 (A) | 7세 (B) | 초1 (G1) |
|---|---|---|---|---|
| 힌트 단위 | 단어 1~2개 | 짧은 구 | 구 | 한 문장 |
| 역할 바꾸기 | 없음 | 단어 1개 고르기 | 단어 카드 2장 → 구 | 문장 틀 채우기 |
| 말하기 | "dog" | "a happy dog" | "a sad cat" | "It is a happy dog." |
| 한 판 라운드 | 5 | 6 | 6 | 8 |

### 6-2. 레벨 1~6 변수표

| 변수 | L1 | L2 | L3 | L4 | L5 | L6 |
|---|---|---|---|---|---|---|
| 펼칠 카드 수(5세) | 2 | 3 | 3 | 3 | 4 | 4 |
| 펼칠 카드 수(6세~초1) | 3 | 4 | 4 | 5 | 5 | 6 |
| 정답과 한 가지만 다른 카드 | 0 | 0 | 1 | 1 | 2 | 3 |
| 힌트에 필요한 태그 수 | 1 | 1 | 1 | 2 | 2 | 2 |
| 역할 바꾸기 단어 보기 수 | 3 | 3 | 4 | 4 | 5 | 5 |
| 힌트 자동 반복 | 2번 | 2번 | 1번 | 1번 | 1번 | 1번 |

### 6-3. 오르내림 규칙 (팀 표준)
판 평균 별 2.0 이상 +1 / 1.5 미만 어려운 판, 두 번 연속 −1 / 그 밖 유지. 아이·연령별 저장. 교실·온라인 판은 레벨 판정에 넣지 않는다. QA용 `?level=`, `?age=`.

## 7. 보상·피드백

| 보상 | 얻는 법 | 쓰는 곳 | 저장 |
|---|---|---|---|
| 별 | 라운드마다 최대 3개 | 판 결과·레벨 판정 | 판별 최고 |
| 앨범 카드 | 맞힌 카드 + 그 힌트(아이가 만든 힌트 포함) | **Popo의 주머니 앨범**(카드와 힌트 다시 듣기, 내가 만든 힌트 표시) | 저장 |
| 바느질 단추 | 별 누적 10·25·50·100개, 역할 바꾸기에서 Popo가 첫 번에 맞힌 횟수 | Popo 주머니 꾸미기(단추·바느질 무늬·주머니 색) | 저장 |

- 정답 연출: 카드가 뒤집히며 Popo 주머니로 쏙, Popo가 주머니에서 몸을 쭉 내밀며 "기쁨" 표정.
- 역할 바꾸기에서 Popo가 맞히면 Popo와 하이파이브, 아이가 만든 힌트가 말풍선으로 한 번 더 읽힘.
- 오답 연출: 카드가 살짝 흔들림, Popo "놀람" 표정. 거친 효과 없음.
- 결과 화면: 별, 이번 판 표현(다시 듣기, 말한 표현 초록 테), 맞힌 수/전체, LEVEL UP!, 새 단추, 홈 · 다시 · 다음.

## 8. 튜터·음성·발음 판정

### 8-1. 튜터
- **Popo 포포**(Phonics Land Pocket Friends): 파란 초승달 모양 몸, 크림색 배, 남색 니트 조끼(파란 단추). 원복 주머니 속에 살며 주머니에서 쏙 고개를 내민다.
- 시트: `01_Phonics_Friends Guide_v1/05_Pocket_Friends/Popo_Views.png`, `Popo_Expressions.png`(표정 6종: 기본·기쁨·화남·슬픔·놀람·불안), 그룹 장면 `00_pocket.png`.
- 게임 연출을 설정에 맞춘다: 카드는 **Popo의 주머니에서 꺼내고** 맞힌 카드는 주머니로 돌아간다. 역할 바꾸기에서 Popo가 짐작할 때 고개를 갸웃(기본 → 놀람), 맞히면 "기쁨". 오답에는 "놀람"·"불안"을 부드럽게. 화남 표정은 쓰지 않는다.
- 묘사 시범: 기분 단어(happy, sad)를 말할 때 Popo가 그 표정을 함께 지어 뜻을 보여 준다(기쁨 = happy, 슬픔 = sad).

### 8-3. 음성
튜터 대사·힌트 구·문장: phonics-api TTS 공통 목소리 + whisper 되읽기. 단어: 레슨팩 공식 녹음 우선 → FPR K 공식 녹음 → TTS. 힌트 구·문장은 자연스러운 억양을 위해 문장 단위로 생성한다.

### 8-4. 말하기 대상 단어와 제외 단어

| 구분 | 내용 |
|---|---|
| 말하기 대상 | 듣고 고르기: 그 라운드 힌트 / 역할 바꾸기: 아이가 만든 힌트 |
| 판정 방식 | 5세 명사 1개 / 6·7세 구의 형용사 + 명사가 모두 들리면 통과(a는 판정하지 않음) / 초1 문장의 빈칸 단어가 들리면 통과(It is·I see는 판정하지 않음) |
| 역할 바꾸기 말하기 힌트(7세·초1) | 인식 결과에서 단어 카드 목록에 있는 단어만 꺼내 힌트로 쓴다. 한국어·목록 밖 단어·비속어는 버리고 "Use the word cards!" |
| 제외 | my. 그림으로 묘사하기 어려운 단어(match, mitt)는 이 게임 카드에서 뺀다 |
| 주의 | 혼동쌍(mouse–mouth)은 같은 판 카드로 함께 쓰지 않는다. 색 단어 red–bed처럼 소리가 비슷한 묘사 단어는 한 판 보기에 함께 넣지 않는다 |
| 교실·온라인 | 교실은 판정 없이 다 같이 말하기. 온라인은 말하기 없이 단어 카드로만 힌트(판정 대기로 흐름이 늦지 않게) |

### 8-5. 발음 판정 (팀 표준)
서버 analyze → judge, 안 되면 기기 안 whisper, 판정 불가면 별 ③ 없이 진행. 대기 8초, 끝 무음 1.2초, 최대 5초(초1 문장은 최대 7초). 2번 실패 Good try, 침묵 약 20초 뒤 진행.

## 9. 화면·UI 요구사항

- **기준:** 16:9, u = min(1vh, 100vw/177.78). 4:3, 스마트폰 가로(844×390, 932×430) 확인. 세로는 돌려 달라는 안내. 교실 큰 화면 1920×1080.
- **상단 바(7.6u / 3u):** 타이틀 — 키·주머니 앨범 / 언어·소리·나가기. 게임 — 별·진행 / LEVEL + 힌트 다시 듣기 / 소리·나가기.
- **배치(듣고 고르기):** 위쪽 Popo와 주머니(높이 22u), 가운데 카드 줄(카드 24u × 30u, 6장까지 한 줄, 스마트폰은 5~6장일 때 두 줄).
- **배치(역할 바꾸기):** 가운데 카드 줄(내 카드에 노란 별 표시, Popo 쪽에서는 안 보이는 연출), 아래 단어 카드 줄(단어 카드 16u × 12u, 그림 + 글자 + 누르면 소리), 7세·초1은 그 위에 문장 틀(빈칸 16u). 오른쪽 아래 "Tell Popo!" 버튼과 마이크 버튼.
- **배치(교실):** 카드 크게(32u × 40u), 아래 투표 막대, 오른쪽 아래 교사 버튼(다음·결과 보기·다 같이 말하기·멈춤). 교사 화면 별도 창(또는 교사 기기)에 정답 카드 표시.
- **터치:** 누르는 요소 최소 12u. 단어 카드는 끌기 대신 탭으로도 빈칸에 들어간다(탭하면 왼쪽 빈칸부터 채움).
- **키보드:** 1~6 카드, Q~T 단어 카드, Enter 힌트 내기, M 말하기, J 점프. (아이가 글자를 치는 입력은 없다)
- **예외:** 마이크 거부·없음 → 말하기 없이, 역할 바꾸기는 단어 카드로만. 오프라인·키 없음 → whisper. 첫 터치 전 소리 잠김. `prefers-reduced-motion` → 카드 뒤집기 대신 페이드.

### 10-1. 기술 단계

| 단계 | 이 게임에서 하는 것 | 필요한 것 |
|---|---|---|
| **A. 정적 웹** | 1인 모드 전체(듣고 고르기·역할 바꾸기), 큰 화면 하나로 하는 교실 모드(교사가 이야기꾼, 아이들이 차례로 나와 탭) | 위 파일 구성. 서버 없음 |
| **B. 교실 연결** | 아이들이 각자 태블릿으로 투표, 교사 기기에만 정답 카드, 투표 막대 실시간 표시 | 실시간 게임 서버(WebSocket), 방 코드·QR 입장, 교사 콘솔 |
| **C. 온라인** | 초1 2~6명 온라인 대전(카드 나누기·힌트·제출·투표·점수), 학생별 기록 | B + API 서버·DB, 로그인·아이 프로필 |

### 10-2. 실시간 이벤트 (B·C)

| 이벤트 | 방향 | 내용 |
|---|---|---|
| room.join | 아이 → 서버 | 방 코드, 프로필 아이콘 |
| hand.deal | 서버 → 각 아이 | 그 아이의 손패 카드 5장(본인에게만) |
| round.start | 서버 → 전체 | 이야기꾼, 단계, 마감 시각(서버 시계) |
| hint.submit | 이야기꾼 → 서버 | 고른 카드 id, 힌트(단어 카드 id 목록) |
| hint.show | 서버 → 전체 | 힌트 단어 목록(카드 id는 보내지 않음) |
| card.submit | 아이 → 서버 | 낸 카드 id |
| vote.open | 서버 → 전체 | 섞인 카드 목록(누가 냈는지 없음) |
| vote.submit | 아이 → 서버 | 고른 카드 id(자기 카드면 서버가 거절) |
| round.result | 서버 → 전체 | 이야기꾼 카드, 투표 분포, 점수 변화, 자동 제출 표시 |
| game.end | 서버 → 전체 | 최종 점수, 이번 판 표현 |

- 이야기꾼 카드와 카드 주인 정보는 `round.result` 전까지 아이 기기에 보내지 않는다. 교실 모드(B)의 정답 카드는 교사 기기에만 보낸다.
- 섞기는 서버에서 Fisher–Yates로 하고, 마감은 서버 시계 기준. 마감 뒤 도착한 제출은 받지 않고 손패에서 자동 제출한다.

## 14. 알려진 이슈·보완 필요

- **높음 — 묘사 카드 제작량:** 단어마다 색·크기·기분·동작이 다른 변형 그림 3~6장이 필요하다. 레슨당 약 60~100장. 레슨팩 공통 자산으로 만들어 다른 게임(Word Link, Word Spectrum)도 쓰게 하는 것을 제안.
- **높음 — 가정용 발음 판정 접속:** 키 없이 쓰는 방식을 정해야 한다. 그전까지는 기기 안 whisper만으로 동작.
- **중간 — 태그 품질:** "big", "happy" 같은 판단은 사람마다 다르다. 태그 시트로 두 사람 이상이 검수하고, 애매한 카드는 그 태그를 빼서 힌트로 쓰지 않는다.
- **중간 — 초1 콘텐츠:** ECP 레슨팩이 초1 묘사 어휘·문장까지 이어지는지 확인 필요.
- **중간 — 온라인 아동 개인정보:** 로그인·기록 전 만 14세 미만 보호자 동의 검토(C 단계 전 완료). 온라인 대전은 채팅·음성 없이 단어 카드로만 소통한다.
- **낮음 — 어휘·생각 트랙 Little Detective와의 구분:** 둘 다 "힌트를 듣고 고르기"가 있다. Little Detective는 한 물건의 부분 단서 추리, Story Cards는 여러 그림 중 묘사에 맞는 그림 고르기 + 내가 설명하기 + 투표로 나눈다. 같은 레슨에서 함께 쓸 때 힌트 문장이 겹치지 않게 한다.
- **낮음 — Popo 등장 겹침:** Popo는 Shop & Count 손님, Little Detective 의뢰인(선택)으로도 나온다. 이 게임에서는 튜터이므로 주머니 무대·카드 소품으로 구별한다.
