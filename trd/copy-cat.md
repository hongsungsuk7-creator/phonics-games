# Copy Cat TRD (카피캣)

> 트랙: 어휘·생각 · 버전 0.1 (제작 착수용) · 작성 2026-11-25
> 한 줄 소개: 두리가 그린 견본 그림과 똑같아지도록, 장난꾸러기 그림자가 흐트러뜨린 캔버스를 고쳐요.

## 1. 개요

| 항목 | 내용 |
|---|---|
| 목적 | 두 그림을 비교해 다른 곳을 찾고 고치며, 사물·색·개수·위치 표현을 익힌다 |
| 대상 | 5~7세(5세 K / 6세 A / 7세 B). 혼자 PC·태블릿·스마트폰으로 한다 |
| 학습 목표 | ① 사물·색 단어 ② 개수+복수(two mugs) ③ 위치 전치사(on, in, under, next to) ④ 음성 지시 듣고 장면 만들기 ⑤ 구·문장 말하기 |
| 인원 | 1인 |
| 한 판 시간 | 5세 그림 5장 약 3~4분 / 6세 6장 약 4~5분 / 7세 6장 약 5~6분(추정) |
| 세계관 | 소풍 매트가 깔린 언덕 위 작은 화실 "Copy Cat Studio". **Duri**(Phonics Land 단일 캐릭터)와 늘 Duri를 따라 하는 **보라색 그림자 친구**가 함께 그림을 그린다. Duri가 견본 그림을 그리면, 장난꾸러기 그림자가 옆 캔버스에 똑같이 그리는 척하면서 몰래 조금씩 다르게 그려 놓는다. 아이는 Duri의 친구가 되어 그림자가 바꿔 놓은 곳을 찾아 똑같이 고친다. 다 고치면 그림자가 Duri와 똑같은 포즈로 하이파이브하고, 완성한 그림은 갤러리 벽에 걸린다. ("Copy Cat"은 "흉내쟁이"라는 뜻으로, 그림자 친구를 가리킨다) |

## 2. 게임 흐름

1. **타이틀:** 햇살 드는 화실, 이젤 두 개, 붓을 든 Duri와 똑같은 포즈를 따라 하는 그림자. START. 왼쪽 위 키·My Gallery, 오른쪽 위 언어·소리·나가기. 첫 터치에 음악 + 인사.
2. **START:** 마이크 권한(팀 표준).
3. **첫 판 시범(방문당 1회, SKIP):** 왼쪽 견본(파란 컵), 오른쪽 캔버스(빨간 컵) → 장갑 손이 캔버스 컵을 톡톡 눌러 파란색으로 바꿈 → Done! → 동그라미 → "이제 혼자 해 봐!".
4. **플레이(그림 한 장):**
   1. 왼쪽 액자에 견본, 오른쪽 이젤에 캔버스가 나온다. Duri가 "Make it the same!" (그림자는 옆에서 시치미 떼는 몸짓)
   2. 아이가 캔버스의 사물을 탭해 바꾸거나(색·종류), 아래 팔레트 서랍에서 끌어 넣고 빼거나(개수), 끌어 옮긴다(위치).
   3. 다 고쳤다고 생각하면 **Done!** 버튼.
   4. 검사: 맞게 고친 곳에 초록 동그라미. 다 맞으면 정답. 남은 곳이 있으면 오답 처리(4-3).
   5. 정답이면 캔버스가 견본처럼 반짝이며 액자에 끼워지고, 고친 곳 하나를 골라 말하기.
5. **말하기:** 그림자가 고친 곳 하나를 손으로 가리키고 Duri가 "Say it!" → 통과 시 별 ③. JUMP 버튼.
6. **결과:** "Masterpiece!" 카드. 별, 이번 판 단어·표현(다시 듣기), 레벨 변화, 갤러리에 걸린 그림. 홈 · 다시 · 다음.

## 3. 주요 게임 요소

| 요소 | 내용 |
|---|---|
| 배경 | 화실(왼쪽 견본 액자 + 오른쪽 이젤 캔버스, 아래 팔레트 서랍). 그림 장면은 방, 공원, 부엌, 캠핑장 4종 |
| 목표 | 캔버스를 견본과 똑같이 만든다(다른 곳을 모두 고침) |
| 장애물(난이도 요소) | 다른 곳 수, 차이 종류(색 → 개수 → 위치), 비슷한 색(red/orange, blue/purple), 견본 가림(L4~: 정해진 시간 뒤 견본이 천으로 덮임), 7세 L5~6 견본 없이 음성 지시만 |
| 조작 | 탭(사물 바꾸기: 누를 때마다 다음 색/종류로), 드래그(서랍 ↔ 캔버스 넣고 빼기, 위치 옮기기), Done! 버튼 |
| 부가 요소 | 견본 다시 보기 버튼(천 걷기, 레벨별 횟수), 지시 다시 듣기(7세), My Gallery(완성 그림 전시, 액자 꾸미기) |

## 4. 게임방식

### 4-1. 캔버스 규칙
- 캔버스의 사물은 장면 안 정해진 **자리(slot)** 에만 놓인다. 위치 문제의 자리 이름: on the table, under the table, in the box, next to the bed 등(장면마다 4~6곳).
- 탭할 때마다 바뀌는 순서는 "변형 목록"을 따른다. 예: mug → 색 목록(red → blue → yellow → green → …) 순환.
- 개수: 서랍에서 끌어 넣으면 +1, 캔버스에서 서랍으로 끌면 −1. **캔버스에 개수 숫자를 표시하지 않는다**(직접 세게 함).
- Done!을 누르기 전에는 맞았는지 알려 주지 않는다(5세 L1~2만 예외: 한 곳을 맞게 고치면 작은 반짝임).

### 4-2. 연령별 문제 형식

| 연령 | 차이 종류 | 예 |
|---|---|---|
| 5세 | 색, 사물 종류 | 견본: blue mug, red mitt, yellow mask / 캔버스: 색이 다름 |
| 6세 | 색, 종류, **개수** | 견본: three mugs on the table / 캔버스: two mugs |
| 7세 | 색, 종류, 개수, **위치**. L5~6은 견본 없이 음성 지시 2~3문장만 | "The mouse is under the table. Two mugs are on the table." |

### 4-3. 정답·오답 처리
- Done!에서 남은 차이가 있으면 1번째: 맞게 고친 곳만 초록 동그라미 + Duri "Almost! Look again." (그림자가 키득 웃는 몸짓) (남은 수는 말하지 않음)
- 2번째: 힌트 — 남은 차이 중 하나의 자리가 반짝인다.
- 3번째: 그림자가 "미안해" 하며 남은 곳을 스스로 고쳐 놓는다 → 별 ① 없음, 다음 그림
- 위치 문제에서 다른 자리에 놓으면 그 자리에 잠깐 붙었다가, Done! 때 판정한다(바로 튕겨 내지 않음).
- 손을 놓으면 8초 뒤 장갑 손이 견본과 캔버스의 같은 자리를 번갈아 가리킨다. 15초마다 반복.

### 4-4. 별 3개 기준 (그림마다)
① 완성 ② 첫 Done!에 완성(힌트·견본 다시 보기 안 씀) ③ 말하기 통과

### 8-1. 튜터
- **Duri 두리**(Phonics Land 단일 캐릭터 4, "A little friend, a playful shadow"): 살구색 몸, 머리 위 말린 털, 보라색 코·손. **보라색 그림자 친구**가 항상 함께 있다.

튜터·구·문장: phonics-api TTS 공통 목소리 + whisper 되읽기. 단어: 레슨팩 공식 녹음 우선. 7세 지시 문장은 한 문장씩 끊어 읽고, 문장마다 다시 듣기 버튼.

### 8-4. 말하기 대상 단어와 제외 단어

| 구분 | 내용 |
|---|---|
| 말하기 대상 | 그림에서 고친 곳 하나(무작위, 단 말하기 판정이 안정적인 단어 우선) |
| 판정 방식 | 5세 색+명사, 6세 숫자+명사(복수형 -s는 판정하지 않음), 7세 명사+위치어(under 등)가 들리면 통과 |
| 제외 | mouth(그림으로 놓기 어려움), my. mice/mouse는 6세 개수 문제에서 말하기 대상에서 뺀다(불규칙 복수) |
| 주의 | 혼동쌍 mat–map–man–mask–match가 같은 그림에 둘 이상 있으면 그중 하나만 말하기 대상으로 |

### 8-5. 발음 판정 (팀 표준)
서버 analyze → judge, 안 되면 기기 안 whisper, 판정 불가면 별 ③ 없이 진행. 듣기 창: 대기 8초, 끝 무음 1.2초, 최대 6초. 2번 실패 Good try, 침묵 약 20초 뒤 진행.

## 9. 화면·UI 요구사항

- **기준:** 16:9, u = min(1vh, 100vw/177.78). 4:3, 스마트폰 가로(844×390, 932×430) 확인. 세로는 돌려 달라는 안내.
- **상단 바(7.6u / 3u):** 타이틀 — 키·My Gallery / 언어·소리·나가기. 게임 — 별·진행 / LEVEL + 지시 다시 듣기 / 소리·나가기.
- **배치:** 왼쪽 견본 액자(70u × 56u), 오른쪽 캔버스(같은 크기), 아래 팔레트 서랍(높이 16u, 사물 아이콘 12u 이상), 오른쪽 아래 Done!(16u).
- **스마트폰:** 두 그림이 나란히 들어가지 않으면(가로 폭 < 800px) 견본을 작게(40%) 왼쪽 위에 띄우고 누르면 크게 보기.
- **터치:** 캔버스 사물 판정 영역 최소 12u. 드래그는 손가락 아래가 가려지지 않게 사물을 손가락보다 6u 위에 띄워 끈다.
- **키보드:** Tab으로 사물 이동, Space 바꾸기, 방향키로 자리 이동, D = Done!, M 말하기, J 점프.
- **예외:** 마이크 거부·없음 → 말하기 없이. 오프라인·키 없음 → whisper. 첫 터치 전 소리 잠김. `prefers-reduced-motion` → 붓질 연출 줄임.

## 14. 알려진 이슈·보완 필요

- **높음 — 가정용 발음 판정 접속:** 키 없이 쓰는 방식을 정해야 한다. 그전까지는 기기 안 whisper만으로 동작.
- **중간 — 스마트폰 화면 폭:** 견본과 캔버스를 나란히 놓기 좁다. 작은 견본 창 방식이 쓸 만한지 아이 테스트로 확인.
- **중간 — 레슨 단어와 장면의 어울림:** m 단어만으로 자연스러운 장면을 만들기 어렵다(meat, match 등). 어색한 단어는 이 게임에서 뺀다.
- **중간 — 7세 음성 지시 모드:** 지시 2~3문장을 기억하며 배치하는 것은 7세에게도 어렵다. 지시를 한 문장씩 들려주고 하나씩 놓게 하는 방식도 함께 시험한다.
- **낮음 — 게임 이름과 캐릭터:** 이름은 Copy Cat이지만 고양이는 나오지 않는다. "흉내쟁이 그림자"라는 뜻을 타이틀 연출(그림자가 Duri를 따라 하는 장면)로 보여 준다.
