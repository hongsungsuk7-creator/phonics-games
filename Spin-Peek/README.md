# Spin & Peek 프로토타입 (v0.1)

> 근거 문서: `TRD\TRD_01_Spin & Peek.md`
> 목적: 게임 흐름·난이도·조작감을 아이 테스트 전에 확인하는 플레이 가능한 시안. 정식 개발 코드가 아니다.

## 실행
- **간단히:** `index.html`을 Chrome에서 연다. 말하기(마이크)는 파일로 열면 막힐 수 있다.
- **말하기까지 확인:** `start.bat` 실행 → 브라우저에서 http://127.0.0.1:5190/ 가 열린다(파이썬 필요). Chrome 권장.
- 태블릿·스마트폰: PC에서 `start.bat` 실행 후, 같은 와이파이에서 PC 주소(예: http://192.168.x.x:5190/)로 접속(Windows 방화벽 허용 필요). 가로 화면, 세로로 들면 돌려 달라는 안내가 나온다.
  - **주의:** 브라우저는 https가 아닌 주소에서 마이크를 막는다. 태블릿·휴대폰에서는 말하기 없이(별 ③ 없이) 진행된다. 기기에서 말하기까지 확인하려면 팀 게임처럼 GitHub Pages(https)에 올려야 한다.
  - iPhone·iPad(Safari)는 브라우저 음성 인식 지원이 제한적이다. 정식 버전은 팀 공통 발음 판정(phonics-api·기기 안 whisper)을 쓰므로 이 제약이 없다.

## 해 보는 순서
1. 타이틀에서 연령(5·6·7세)을 고르고 START.
2. 처음 한 번은 Nubi 시범(장갑 손)이 나온다. 오른쪽 아래 SKIP으로 건너뛸 수 있다.
3. 마법 문이 돌며 문 너머 물건이 순간순간 보인다 → 보기를 고른다.
   - 5세: 색+물건 1개 / 6세: 물건 2개(순서 무관) / 7세: 2~3개를 나온 순서대로
4. 맞히면 문이 열리고 말하기 → 다음. 한 판이 끝나면 결과 화면(별, 단어 다시 듣기, 레벨 변화, 열쇠).

## TRD 반영 범위

| TRD 항목 | 반영 내용 |
|---|---|
| 게임 흐름(2장) | 타이틀 → 마이크 요청 → 첫 판 시범(SKIP) → 문제 → 말하기 → 결과 |
| 게임방식(4장) | 문 회전·노출 횟수, 정답 최소 3번 노출, 6세 2개·7세 순서, 오답 1회 격려 → 2회 힌트(오답 흐리게·정답 반짝) → 3회 정답 공개, 손을 놓으면 8초 뒤 안내·15초마다 반복, 별 3개 기준 |
| 레벨(6장) | 레벨 1~6 변수표 그대로(회전 시간, 노출 횟수, 보기 수, 방해 보기 종류, 미끼 번쩍임, 다시 보기 횟수). 판 평균 별 2.0 이상 +1, 1.5 미만 두 번 연속 −1, 연령별로 따로 저장 |
| 보상(7장) | 문제별 별, 결과 화면 단어 목록(누르면 다시 듣기, 말한 단어 초록 테), 별 12개마다 열쇠 1개(Key Ring) |
| 튜터(8장) | Nubi 시트 표정 4종(neutral·curious·listening·delighted)을 상황별로 사용. 대사 영어·한국어(언어 토글, 처음 한국어) |
| 말하기(8-4·8-5) | 핵심 단어(색·명사, 7세는 순서)가 들리면 통과, 2번 틀리면 Good try, 침묵 2번이면 넘어감, JUMP, 마이크 없으면 별 ③ 없이 진행 |
| 화면(9장) | 16:9 무대 + 단위 u 스케일, 상단 바, 4:3·스마트폰 가로 대응, 세로 화면은 돌려 달라는 안내, 키보드(1~6 보기, R 다시 보기, J 점프) |

## 프로토타입 한계 (정식 개발에서 바꿀 것)
- **그림:** 레슨팩 대표 이미지 대신 임시 그림(이모지, 색 바꾸기용 도형 5종: mug·mitt·mask·mail·mushroom).
- **음성:** 레슨팩 공식 녹음·공통 TTS 목소리 대신 **브라우저 내장 음성**(기기마다 목소리가 다름).
- **발음 판정:** phonics-api 대신 **브라우저 음성 인식(Chrome)**. 정확도·판정 기준이 팀 표준과 다르다.
- **3D:** three.js 모델 대신 CSS 3D 회전과 시트 이미지.
- 공통 기록(`phonics.progress`), 아이 프로필, 꾸미기 화면(Key Ring 열기)은 아직 없다.
