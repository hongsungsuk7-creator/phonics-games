# Maze Quest 프로토타입 (v0.1)

> 근거 문서: `TRD\TRD_06_Maze Quest.md`
> 목적: 게임 흐름·난이도·조작감을 아이 테스트 전에 확인하는 플레이 가능한 시안. 정식 개발 코드가 아니다.

## 실행
- **간단히:** `index.html`을 Chrome에서 연다. 말하기(마이크)는 파일로 열면 막힐 수 있다.
- **말하기까지 확인:** `start.bat` 실행 → http://127.0.0.1:5195/ (파이썬 필요, Chrome 권장).
- 태블릿·스마트폰: PC에서 `start.bat` 실행 후 같은 와이파이에서 PC 주소(예: http://192.168.x.x:5195/)로 접속(Windows 방화벽 허용 필요). 가로 화면, 세로로 들면 돌려 달라는 안내가 나온다.
  - **주의:** 브라우저는 https가 아닌 주소에서 마이크를 막는다. 태블릿·휴대폰에서는 말하기 없이(별 ③ 없이) 진행된다. GitHub Pages(https)에 올리면 기기에서도 말하기가 된다.
  - iPhone·iPad(Safari)는 브라우저 음성 인식 지원이 제한적이다. 정식 버전은 팀 공통 발음 판정(phonics-api·기기 안 whisper)을 쓰므로 이 제약이 없다.
- 공용 파일 `../_shared/kit.js`, `../_shared/kit.css`를 함께 쓴다(Copy Cat·Little Detective·Shop & Count·Maze Quest·Photo Safari 공통: 화면 맞춤, 음성, 말하기 판정, 레벨 규칙, 결과 화면, QA 패널). 폴더째 옮길 때 `_shared`도 함께 옮긴다.

## 해 보는 순서
1. 연령을 고르고 START. 처음 한 번은 시범(SKIP 가능).
2. 미션(오른쪽 위, 🔊 다시 듣기)대로 물건을 모아 🎁까지 간다.
   - **5·6세:** 미로 위에서 손가락을 떼지 않고 길을 그린다. 손을 떼면 Bobo가 걷는다. 끊어 그려도 Bobo가 멈춘 곳에서 이어진다. ↶ 지우개.
   - **7세:** 화살표 카드를 놓고(카드를 누르면 1→2→3… 칸 수), GO. 벽에 부딪힌 카드는 주황색.
   - L5~6: 🗝️ 열쇠를 주우면 블록 벽(Shape Builders Stretch)이 비켜 준다.
3. 도착하면 말하기 → 다음. 결과 화면에 섬 지도 칸.

## TRD 반영 범위
| TRD 항목 | 반영 내용 |
|---|---|
| 미로 규칙(4-1) | 자동 생성(항상 풀 수 있음), 미션 아이템·방해 아이템 배치, 방해 아이템은 감점 없이 별 ②만, 순서가 틀리면 아이템이 그대로 남고 실패 1회 |
| 길 그리기 | 칸 중심에 붙음, 벽에 닿으면 마지막 칸에서 멈춤(처음부터 다시 안 함), 되돌아가면 지워짐, 열쇠를 지나는 선은 문 통과 가능 |
| 명령 카드(4-3) | ↑↓←→ + 칸 수(카드 탭), 슬롯 4~12, 벽에 부딪히면 직전 칸에서 멈추고 그 카드 주황 표시, 프로그램은 Bobo의 현재 위치에서 이어 실행 |
| 실패(4-4) | 1번째 안내, 2번째 다음 3칸 발자국, 3번째 Bobo가 직접 길을 걸어 보여 줌(별 없음) |
| 연령·레벨(6) | 미로 4×4~7×7, 방해 아이템 0~3, 열쇠·블록 벽 L5~6, 6세 L4~ 순서, 7세 L4~ 미션 음성만(🎧) |
| 튜터(8) | Bobo(Classmate Friends) 표정 3종 + 미로 속 전신, 말하기 5세 단어 / 6세 "I got the map and the mug." / 7세 "First the mitt, then the mask." |

공통: 레벨은 고르지 않음(판 평균 별 2.0 이상 +1, 1.5 미만 두 번 연속 −1, 연령별 저장), 별 3개 기준(맞힘 / 첫 시도·힌트 없이 / 말하기), 손을 놓으면 8초 뒤 안내·15초마다 반복, 말하기 2번 실패 Good try·침묵 2번이면 넘어감·JUMP, 마이크 없으면 별 ③ 없이 진행, 언어 토글(처음 한국어), 16:9 + 4:3 + 스마트폰 가로, 세로는 돌려 달라는 안내.

## 프로토타입 한계 (정식 개발에서 바꿀 것)
- **그림:** 레슨팩 대표 이미지 대신 임시 그림(이모지, 색 바꾸기용 도형).
- **음성:** 레슨팩 공식 녹음·공통 TTS 목소리 대신 브라우저 내장 음성(기기마다 목소리가 다름).
- **발음 판정:** phonics-api 대신 브라우저 음성 인식(Chrome). 정확도·판정 기준이 팀 표준과 다르다.
- 공통 기록(`phonics.progress`), 아이 프로필, 컬렉션 꾸미기 화면은 아직 없다(결과 화면에 모은 개수만 표시).

## QA 옵션
- 화면 아래 가운데 **QA** 버튼: 레벨 강제, 말하기 모드(실제 인식 / 항상 통과 / 항상 오답 / 마이크 없음), 첫 판 시범(방문당 1회 / 매번 / 끄기), 저장 초기화.
- 주소 옵션: `?age=5|6|7&level=1~6&speech=real|ok|wrong|off&demo=auto|always|never&autostart=1&mute=1``
- 자동 점검(2026-11-25, Playwright·Chrome): 5세 L2(길 일부 그리기 → 이어 그리기 → 도착 → 한 판 완주 → 결과), 6세 L5 열쇠·블록 벽·순서 3개, 7세 L3 명령 카드(벽 부딪힘 2번 → 발자국 힌트 → 완주 → 결과), 7세 L6 음성 미션(스마트폰), 첫 판 시범 — 콘솔 오류 0.
